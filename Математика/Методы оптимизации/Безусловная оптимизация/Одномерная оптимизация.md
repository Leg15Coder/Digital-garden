Рассматривается задача минимизации функции одной переменной на отрезке:$$f : [a; b] \to \mathbb{R}, \qquad f(x) \xrightarrow{x \in [a; b]} \min$$

### Унимодальные и квазивыпуклые функции

==Опр.== **Унимодальная функция** *(на отрезке $[a; b]$)* - функция $f : [a; b] \to \mathbb{R}$ т.ч.$$\exists \hat{x} \in [a; b]\ :\ \begin{cases} \forall x_1, x_2\ (a \le x_1 < x_2 < \hat{x})\ :\ f(x_1) > f(x_2) \\ \forall x_1, x_2\ (\hat{x} < x_1 < x_2 \le b)\ :\ f(x_1) < f(x_2) \end{cases}$$
==Опр.== **Квазивыпуклая функция** *($f : X \to \mathbb{R}$ на [[Выпуклые множества и оболочки|выпуклом множестве]] $X$)* - функция т.ч.$$\forall x_1, x_2 \in X\ \forall \alpha \in [0; 1]\ :\ f(\alpha x_1 + (1 - \alpha) x_2) \le \max\limits_{i \in \{1, 2\}} f(x_i)$$Если при $x_1 \neq x_2$ и $\alpha \in (0; 1)$ неравенство строгое, функция называется **строго квазивыпуклой**.

==Опр.== **Квазивогнутая функция** - функция $f : X \to \mathbb{R}$ т.ч. функция $(-f)$ является квазивыпуклой.

==Опр.== **Квазилинейная функция** - функция, являющаяся одновременно квазивыпуклой и квазивогнутой.

### Критерий квазивыпуклости (б/д)

Функция $f : X \to \mathbb{R}$ квазивыпукла на выпуклом множестве $X$ $\iff$ все её множества нижнего уровня выпуклы:$$\forall A \in \mathbb{R}\ :\ \{x \in X \mid f(x) \le A\} \text{ - выпуклое множество}$$

### Единственность минимума и связь унимодальности с квазивыпуклостью

==Утв.== Для унимодальных функций на $[a; b]$ справедливы два свойства:
1. Если $f$ унимодальна на $[a; b]$ с точкой минимума $\hat{x}$ и $\exists x \in [a; b]\ :\ x \in \arg\operatorname{glob}\min\limits_{[a; b]} f$, то $x = \hat{x}$ *(глобальный минимум единственен)*.
2. Если $f \in C_{[a; b]}$, то $f$ унимодальна на $[a; b]$ $\iff$ $f$ строго квазивыпукла на $[a; b]$.

### Свойство локализации минимума унимодальной функции

==Утв.== Пусть $f$ - унимодальная функция на $[a; b]$, $\hat{x} = \arg\operatorname{glob}\min\limits_{[a; b]} f$, и выбраны две точки $x_1, x_2 \in [a; b]$ т.ч. $x_1 < x_2$. Тогда:
1. $f(x_1) \le f(x_2) \implies \hat{x} \in [a; x_2]$;
2. $f(x_1) \ge f(x_2) \implies \hat{x} \in [x_1; b]$.
#### Доказательство
1. Допустим противное в п. 1: пусть $\hat{x} \notin [a; x_2]$, т.е. $\hat{x} > x_2 > x_1$. В силу унимодальности на $[a; \hat{x})$ функция $f$ строго убывает, откуда $f(x_2) < f(x_1)$ - противоречие с условием $f(x_1) \le f(x_2)$.
2. Пункт 2 доказывается аналогично: предположение $\hat{x} < x_1 < x_2$ влечёт строгое возрастание $f$ на $(\hat{x}; b]$ и противоречит $f(x_1) \ge f(x_2)$.

### Одномерные методы локализации решения

Пусть в задаче $f(x) \xrightarrow{x \in [a; b]} \min$ строится последовательность вложенных отрезков $\{[a_n; b_n]\}_{n=0}^\infty$:$$\forall n \in \mathbb{N}_0\ :\ [a_n; b_n] \subseteq [a; b], \quad [a_{n+1}; b_{n+1}] \subset [a_n; b_n], \quad \hat{x} \in [a_n; b_n]$$

==Опр.== **Приближённое решение** *($\tilde{x}$ на $k$-м шаге локализации)* - любая точка отрезка $[a_k; b_k]$ *(как правило, его середина: $\tilde{x} = \frac{a_k + b_k}{2}$)*. Гарантированная точность:$$|\tilde{x} - \hat{x}| \le b_k - a_k \qquad \left(\text{для середины: } |\tilde{x} - \hat{x}| \le \frac{b_k - a_k}{2}\right)$$

### Метод дихотомии *(метод деления отрезка пополам)*

Для унимодальной функции $f$ на каждом шаге $k$ отрезок $[a_k; b_k]$ делится на четыре равные части точками:$$c_k = \frac{a_k + b_k}{2}, \qquad y_k = \frac{a_k + c_k}{2}, \qquad z_k = \frac{c_k + b_k}{2}$$На шаге сравниваются значения $f(y_k), f(c_k), f(z_k)$, и по свойству локализации выбирается новый отрезок длины $\frac{b_k - a_k}{2}$:
1. $f(y_k) < f(c_k) < f(z_k) \implies [a_{k+1}; b_{k+1}] = [a_k; c_k]$, $c_{k+1} = y_k$;
2. $f(y_k) > f(c_k) > f(z_k) \implies [a_{k+1}; b_{k+1}] = [c_k; b_k]$, $c_{k+1} = z_k$;
3. $f(c_k) \le f(y_k)$ и $f(c_k) \le f(z_k) \implies [a_{k+1}; b_{k+1}] = [y_k; z_k]$, $c_{k+1} = c_k$.

![[dichotomy_method.png]]

> [!example] Пример: **Метод дихотомии для $f(x) = x^2 - 6x + 10$ на $[0; 6]$**
> Начальные данные: $a_0 = 0,\ c_0 = 3,\ b_0 = 6$. Значение в центре: $f(c_0) = 1$.
> * **Шаг 1:** $y_0 = \frac{3}{2} = 1.5$, $z_0 = \frac{9}{2} = 4.5$. Вычисляем $f(y_0) = 3.25$, $f(z_0) = 3.25$. Т.к. $f(c_0) < f(y_0)$ и $f(c_0) < f(z_0)$, переходим к отрезку $a_1 = y_0 = 1.5$, $b_1 = z_0 = 4.5$, $c_1 = 3$.
> * **Шаг 2:** $y_1 = 2.25$, $z_1 = 3.75$. Вычисляем $f(y_1) = 1.5625$, $f(z_1) = 1.5625$. Снова $f(c_1) < f(y_1), f(z_1)$, откуда $a_2 = 2.25$, $b_2 = 3.75$, приближённое решение $\tilde{x} = \frac{a_2 + b_2}{2} = 3$.

### Метод золотого сечения

Отрезок $[a; b]$ делится точками $y, z \in (a; b)$ в золотом отношении, определяемом пропорцией:$$\frac{b - a}{b - y} = \frac{b - y}{y - a} = \tau := \frac{1 + \sqrt{5}}{2}$$Отсюда выражаются **малая** и **большая** золотые точки отрезка $[a; b]$:$$y(a; b) = a + \frac{2}{3 + \sqrt{5}}(b - a) = a + \tau^{-2}(b - a), \qquad z(a; b) = a + \frac{\sqrt{5} - 1}{2}(b - a) = a + \tau^{-1}(b - a)$$

![[golden_section_ratio.png]]

#### Свойства золотых точек

==Утв.== Для малых и больших золотых точек $y = y(a; b)$ и $z = z(a; b)$ отрезка $[a; b]$ справедливы соотношения:
1. $z - a = b - y = \tau^{-1}(b - a)$;
2. $y$ - большая золотая точка отрезка $[a; z]$;
3. $z$ - малая золотая точка отрезка $[y; b]$.

#### Алгоритм метода золотого сечения

0. **Инициализация:** $a_1 := a$, $b_1 := b$, $y_1 := y(a; b)$, $z_1 := z(a; b)$.
1. **Шаг $k$ ($k \ge 1$):**
   1. Вычислить ещё не вычисленное значение среди $f(y_k)$ и $f(z_k)$ *(на шаге $k = 1$ вычисляются оба значения)*.
   2. Проверить условие $f(y_k) \le f(z_k)$:
      * если $f(y_k) \le f(z_k)$: $a_{k+1} := a_k,\quad b_{k+1} := z_k,\quad z_{k+1} := y_k,\quad y_{k+1} := y(a_{k+1}; b_{k+1})$;
      * если $f(y_k) > f(z_k)$: $a_{k+1} := y_k,\quad b_{k+1} := b_k,\quad y_{k+1} := z_k,\quad z_{k+1} := z(a_{k+1}; b_{k+1})$.

![[golden_section_steps.png]]

> [!tip] Преимущество метода
> За счёт переиспользования одной из золотых точек на каждом шаге ($k \ge 2$) значение функции $f$ вычисляется ровно **1 раз** *(экономия вычислений оракула по сравнению с методом дихотомии, требующим 2 вычисления на шаг)*.

В силу свойства локализации минимума унимодальной функции $\forall k \in \mathbb{N}\ :\ \hat{x} = \arg\operatorname{glob}\min\limits_{[a; b]} f \in [a_k; b_k]$, а после $k$ шагов сжатия погрешность приближённого решения удовлетворяет оценке:$$|\tilde{x} - \hat{x}| \le b_{k+1} - a_{k+1} = \tau^{-k}(b - a)$$
