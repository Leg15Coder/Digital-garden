==Опр.== **Непрерывная функция** *($f$ в т. $x_0$)* - $\lim\limits_{x \to x_0,\ x \in Df}f(x) = f(x_0)\ (\in \mathbb{R})$

==Опр.== $C_A = \{f\ :\ A \to \mathbb{R}\ |\ \forall x_o \in A\ :\ f\ \text{непрерывна в}\ x_0\}$

==Опр.== **Ограниченная функция** - функция $f: A \to \mathbb{R}$, для которой : $\exists C > 0 \ \forall x \in A \ : \ |f(x)| \le C$.

==Опр.== **Точная верхняя грань функции** *(супремум функции)* - число $M = \sup\limits_{x \in Df} f(x) \in \mathbb{R} \cup \{+\infty\}$, удовлетворяющее условиям:
1. $\forall x \in Df \ : \ f(x) \le M$;
2. $\forall M' < M \ \exists x \in Df \ : \ f(x) > M'$.

==Опр.== **Точная нижняя грань функции** *(инфимум функции)* - число $m = \inf\limits_{x \in Df} f(x) \in \mathbb{R} \cup \{-\infty\}$, удовлетворяющее условиям:
1. $\forall x \in Df \ : \ f(x) \ge m$;
2. $\forall m' > m \ \exists x \in Df \ : \ f(x) < m'$.

==Опр.== **Максимизирующая последовательность** - последовательность точек $\{x_n\}_{n=1}^\infty \subset Df$, удовлетворяющая условию $\lim\limits_{n \to \infty} f(x_n) = \sup\limits_{x} f(x)$.
