==Опр.== **Диаметр множества** $I \subset \mathbb{R}$: $\operatorname{diam} I = \sup\limits_{x, y \in I} |x - y|$. Для непустого ограниченного промежутка $I$: $m(I) = \sup\limits_{x \in I} x - \inf\limits_{x \in I} x = \operatorname{diam} I$ *(и $m(\emptyset) = 0$)*.

==Опр.== **Мера клетки** $Q = \prod\limits_{i=1}^d I_i \in \Theta_d$ (см. [[Клетки и клеточные множества|клетки]]):$$m(Q) = \prod\limits_{i=1}^d m(I_i)$$

### Конечная аддитивность меры клетки

Если клетка $A \in \Theta_d$ разбита на конечное число попарно непересекающихся клеток $\{Q_k\}_{k=1}^n \subset \Theta_d$ ($A = \bigsqcup\limits_{k=1}^n Q_k$), то:$$m(A) = \sum\limits_{k=1}^n m(Q_k)$$

#### Доказательство
1. Индукция по $d$: при $d = 1$ разбиение промежутка $A$ на промежутки $Q_1, \dots, Q_n$ после упорядочения по координате даёт телескопическую сумму $\sum\limits_{k=1}^n (b_k - a_k) = b - a = m(A)$.
2. Пусть утверждение верно для $d - 1$. Обозначим все концевые точки $d$-х проекций клеток $A, Q_1, \dots, Q_n$ на оси $x_d$ (упорядоченные: $c_0 < c_1 < \dots < c_r$). На каждом интервале $(c_{s-1}; c_s)$ горизонтальное сечение $A$ совпадает с клеткой $A' \in \Theta_{d-1}$, а сечения тех $Q_k$, проекции которых содержат $(c_{s-1}; c_s)$, образуют конечное дизъюнктное разбиение $A'$. По предположению индукции на каждом слое сумма $(d-1)$-мерных мер этих сечений равна $m_{d-1}(A')$. Умножая на $(c_s - c_{s-1})$ и суммируя по $s = 1, \dots, r$, получаем $\sum\limits_{k=1}^n m(Q_k) = m(A)$.

#### Следствие (корректность меры клеточного множества)
Если клеточное множество $E$ представлено двумя дизъюнктными разбиениями $E = \bigsqcup\limits_{k=1}^n Q_k = \bigsqcup\limits_{\ell=1}^r P_\ell$, то $Q_k = \bigsqcup\limits_{\ell=1}^r (Q_k \cap P_\ell)$ и $P_\ell = \bigsqcup\limits_{k=1}^n (Q_k \cap P_\ell)$, откуда $\sum\limits_{k=1}^n m(Q_k) = \sum\limits_{k=1}^n \sum\limits_{\ell=1}^r m(Q_k \cap P_\ell) = \sum\limits_{\ell=1}^r m(P_\ell)$.

==Опр.== **Мера клеточного множества** $E = \bigsqcup\limits_{k=1}^n Q_k \in \mathcal{S}_d$: $m(E) := \sum\limits_{k=1}^n m(Q_k)$ *(не зависит от выбора разбиения)*.

### Конечная аддитивность и субаддитивность на $\mathcal{S}_d$

1. Для любых попарно непересекающихся $A_1, \dots, A_n \in \mathcal{S}_d$: $m\left(\bigsqcup\limits_{k=1}^n A_k\right) = \sum\limits_{k=1}^n m(A_k)$.
2. Для любых $A, B \in \mathcal{S}_d$ с $A \subset B$: $m(A) \le m(B)$ *(монотонность)*.
3. Для любых $A, A_1, \dots, A_n \in \mathcal{S}_d$ с $A \subset \bigcup\limits_{k=1}^n A_k$: $m(A) \le \sum\limits_{k=1}^n m(A_k)$ *(конечная субаддитивность)*.

#### Доказательство субаддитивности
Сначала, если $\forall k\ :\ A_k \subset A$, то $A = \bigcup\limits_{k=1}^n A_k = \bigsqcup\limits_{j=1}^M D_j$, где каждая клетка $D_j$ лежит в некотором $A_k$. Разбивая $D_j$ по индексам $k$ (относя каждое $D_j$ к первому содержащему его $A_k$), по конечной аддитивности и монотонности получаем $m(A) \le \sum\limits_{k=1}^n m(A_k)$. В общем случае $A = \bigcup\limits_{k=1}^n (A_k \cap A) \implies m(A) \le \sum\limits_{k=1}^n m(A_k \cap A) \le \sum\limits_{k=1}^n m(A_k)$.

### Счётная субаддитивность и счётная аддитивность клеточной меры

1. *(Счётная субаддитивность)* Если клетка $A \in \Theta_d$ покрыта счётным набором клеток $\{Q_k\}_{k=1}^\infty \subset \Theta_d$ ($A \subset \bigcup\limits_{k=1}^\infty Q_k$), то $m(A) \le \sum\limits_{k=1}^\infty m(Q_k)$.
2. *(Счётная аддитивность)* Если $\forall k \in \mathbb{N}\ :\ Q_k \in \Theta_d$ попарно не пересекаются и $A = \bigsqcup\limits_{k=1}^\infty Q_k \in \Theta_d$, то $m(A) = \sum\limits_{k=1}^\infty m(Q_k)$.

#### Доказательство
1. **Счётная субаддитивность**: при $m(A) = 0$ неравенство очевидно. Пусть $m(A) > 0$ и $\varepsilon > 0$. Сузим клетку $A$ до замкнутой клетки (компакта) $\tilde{A} \subset A$ так, чтобы $m(\tilde{A}) > m(A) - \varepsilon$. Каждую клетку $Q_k$ расширим до открытой клетки $\hat{Q}_k \supset Q_k$ так, чтобы $m(\hat{Q}_k) < m(Q_k) + \frac{\varepsilon}{2^k}$. Тогда $\{\hat{Q}_k\}_{k=1}^\infty$ - открытое покрытие компакта $\tilde{A}$. По [[Лемма Гейне-Бореля|лемме Гейне-Бореля]] $\exists n \in \mathbb{N}\ :\ \tilde{A} \subset \bigcup\limits_{k=1}^n \hat{Q}_k$. По конечной субаддитивности:$$m(A) - \varepsilon < m(\tilde{A}) \le \sum\limits_{k=1}^n m(\hat{Q}_k) < \sum\limits_{k=1}^\infty \left(m(Q_k) + \frac{\varepsilon}{2^k}\right) = \sum\limits_{k=1}^\infty m(Q_k) + \varepsilon$$В силу произвольности $\varepsilon > 0$ получаем $m(A) \le \sum\limits_{k=1}^\infty m(Q_k)$.

2. **Счётная аддитивность**: неравенство $m(A) \le \sum\limits_{k=1}^\infty m(Q_k)$ уже доказано в п. 1. Для обратного неравенства при $\forall n \in \mathbb{N}$ разность $A \setminus \bigsqcup\limits_{k=1}^n Q_k = \bigsqcup\limits_{j=1}^\ell B_j$ является конечным дизъюнктным объединением клеток. По конечной аддитивности:$$m(A) = \sum\limits_{k=1}^n m(Q_k) + \sum\limits_{j=1}^\ell m(B_j) \ge \sum\limits_{k=1}^n m(Q_k)$$Переходя к пределу при $n \to \infty$, получаем $m(A) \ge \sum\limits_{k=1}^\infty m(Q_k)$, откуда $m(A) = \sum\limits_{k=1}^\infty m(Q_k)$.
