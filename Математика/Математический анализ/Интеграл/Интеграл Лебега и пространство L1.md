### Интеграл Лебега и пространство $L^1(E)$

Для $a \in \overline{\mathbb{R}}$ положим $a^+ = \begin{cases} a, & a > 0 \\ 0, & a \le 0 \end{cases}$ и $a^- = (-a)^+$, тогда $a = a^+ - a^-$ и $|a| = a^+ + a^-$.

==Опр.== Пусть $E \in \mathcal{M}_d$ и $f: E \to \overline{\mathbb{R}}$ измерима по Лебегу. Если хотя бы один из [[Теорема Леви о монотонной сходимости|интегралов неотрицательных функций]] $\int\limits_E f^+\,d\mu$ и $\int\limits_E f^-\,d\mu$ конечен, то **интеграл Лебега** от $f$ по $E$ определяется как:$$\int\limits_E f\,d\mu := \int\limits_E f^+\,d\mu - \int\limits_E f^-\,d\mu$$*(Если оба интеграла равны $+\infty$, то интеграл Лебега от $f$ не существует.)*

==Опр.== Функция $f$ **интегрируема по Лебегу** на $E$ ($f \in L^1(E)$), если оба интеграла $\int\limits_E f^+\,d\mu$ и $\int\limits_E f^-\,d\mu$ конечны *(эквивалентно $\int\limits_E |f|\,d\mu < +\infty$)*.

==Опр.== При $p \ge 1$ пространство **$L^p(E)$**: $f \in L^p(E) \iff f$ измерима на $E$ и $\int\limits_E |f|^p\,d\mu < +\infty$.

### Аддитивность и линейность интеграла Лебега

Если $f, g \in L^1(E)$ и $\alpha, \beta \in \mathbb{R}$, то $(\alpha f + \beta g) \in L^1(E)$ и:$$\int\limits_E (\alpha f + \beta g)\,d\mu = \alpha \int\limits_E f\,d\mu + \beta \int\limits_E g\,d\mu, \qquad \left|\int\limits_E f\,d\mu\right| \le \int\limits_E |f|\,d\mu$$

#### Доказательство
1. Положим $h = f + g$. Т.к. $|h| \le |f| + |g|$, то $\int\limits_E |h|\,d\mu \le \int\limits_E |f|\,d\mu + \int\limits_E |g|\,d\mu < +\infty \implies h \in L^1(E)$.
2. Из $h^+ - h^- = f^+ - f^- + g^+ - g^-$ следует $h^+ + f^- + g^- = h^- + f^+ + g^+$, где все слагаемые неотрицательны. По аддитивности интеграла для неотрицательных функций:$$\int\limits_E h^+\,d\mu + \int\limits_E f^-\,d\mu + \int\limits_E g^-\,d\mu = \int\limits_E h^-\,d\mu + \int\limits_E f^+\,d\mu + \int\limits_E g^+\,d\mu$$Перенося конечные слагаемые, получаем $\int\limits_E (f + g)\,d\mu = \int\limits_E f\,d\mu + \int\limits_E g\,d\mu$.
3. Вынесение $\alpha \in \mathbb{R}$ проверяется отдельно для $\alpha \ge 0$ и $\alpha = -1$ (где $(-f)^+ = f^-$, $(-f)^- = f^+$). Оценка модуля следует из $\left|\int\limits_E f^+\,d\mu - \int\limits_E f^-\,d\mu\right| \le \int\limits_E f^+\,d\mu + \int\limits_E f^-\,d\mu = \int\limits_E |f|\,d\mu$.
