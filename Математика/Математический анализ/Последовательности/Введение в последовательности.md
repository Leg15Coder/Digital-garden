==Опр.== **Числовая последовательность** - функция $x: \mathbb{N} \to \mathbb{R}$, сопоставляющая каждому натуральному числу $n \in \mathbb{N}$ вещественное число $x_n = x(n)$. Обозначается - $\{x_n\}_{n=1}^\infty \subset \mathbb{R}$.

==Опр.== **Подпоследовательность** - последовательность $\{x_{n_k}\}_{k=1}^\infty$, образованная выбором строго возрастающей последовательности натуральных индексов $\{n_k\}_{k=1}^\infty \subset \mathbb{N}$ (т.ч. $\forall i < j\ :\ n_i < n_j$) последовательности $\{x_n\}_{n=1}^\infty$.

==Опр.== **Частичный предел** *(предельная точка)* - элемент $a \in \overline{\mathbb{R}}$, являющийся пределом некоторой подпоследовательности $\{x_{n_k}\}$ рассматриваемой последовательности $\{x_n\}$, т.е. $\exists \{n_k\}_{k=1}^\infty \subset \mathbb{N} \ :\ \lim\limits_{k \to \infty} x_{n_k} = a$.

==Опр.== **Ограниченная последовательность** - последовательность $\{x_n\}$, для которой: $\exists C > 0 \ \forall n \in \mathbb{N} \ : \ |x_n| \le C$.

==Опр.== **Фундаментальная последовательность** *(последовательность Коши)* - последовательность $\{x_n\}$, для которой : $\forall \varepsilon > 0 \ \exists N \in \mathbb{N} \ \forall n, m > N \ : \ |x_n - x_m| < \varepsilon$.
