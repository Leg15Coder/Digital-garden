### Утверждение (Ограниченность фундаментальной последовательности)

- Если последовательность $\{x_n\}$ [[Введение в последовательности|фундаментальна]], то она ограничена.

#### Доказательство

1. Фиксируем $\varepsilon = 1$. По определению фундаментальности : $\exists N \in \mathbb{N} \ \forall n, m > N \ : \ |x_n - x_m| < 1$.
2. Возьмём $m = N + 1$. Тогда $\forall n > N \ : \ |x_n - x_{N+1}| < 1 \ \Rightarrow \ |x_n| < |x_{N+1}| + 1$.
3. Положим $C = \max_{i \in \overline{1,N}}\limits(|x_i|, |x_{N+1}| + 1)$.
4. Тогда $\forall n \in \mathbb{N} \ : \ |x_n| \le C$, что означает ограниченность последовательности $\{x_n\}$.

### Критерий Коши сходимости последовательности

$\exists \lim \limits_{n \to \infty}x_n = a \in \mathbb{R}$ $\iff$ $\{x_n\}$ фундаментальна.

#### Доказательство

##### Необходимость ($\Rightarrow$):
1. Пусть $\varepsilon > 0$. По определению предела: $\exists N \in \mathbb{N}\ \forall n > N\ :\ |x_n - a| < \varepsilon$
2. Возьмём произвольные $n, m > N$. По [[Неравенство треугольника|неравенству треугольника]]: $$|x_n - x_m| = |(x_n - a) + (a - x_m)| \le |x_n - a| + |x_m - a| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$$Следовательно, последовательность $\{x_n\}$ фундаментальна.

##### Достаточность ($\Leftarrow$)
1. Пусть последовательность $\{x_n\}$ фундаментальна. По утв. об ограниченности последовательность $\{x_n\}$ ограничена.
2. По [[Теорема Больцано-Вейерштрасса|Т. Б-В]] из $\{x_n\}$ можно выделить сходящуюся подпоследовательность $\{x_{n_k}\}$: $\lim\limits_{k \to \infty} x_{n_k} = a \in \mathbb{R}$
3. Докажем, что вся последовательность $\{x_n\}$ сходится к $a$. Фиксируем произвольное $\varepsilon > 0$. Ввиду фундаментальности $\{x_n\}$ : $\exists N \in \mathbb{N} \ \forall n, m > N \ : \ |x_n - x_m| < \frac{\varepsilon}{2}$.
4. Ввиду сходимости подпоследовательности $x_{n_k} \to a$ : $\exists K \in \mathbb{N} \ \forall k > K \ : \ n_k > N$ и $|x_{n_k} - a| < \frac{\varepsilon}{2}$.
5. Зафиксируем индекс $k > K$. Тогда $\forall n > N$, заменяя $m$ на $n_k > N$, получаем:$$|x_n - a| \le |x_n - x_{n_k}| + |x_{n_k} - a| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$$
6. Следовательно, $\lim\limits_{n \to \infty} x_n = a$.

> [!INFO] Геометрическая интерпретация критерия Коши
> Условие фундаментальности означает, что при достаточно больших номерах $n$ и $m$ расстояние между любыми двумя членами последовательности $|x_n - x_m|$ становится сколь угодно малым. Все элементы сжимаются в локальное сгущение, что заставляет последовательность сходиться к единственной точке пространства $\mathbb{R}$.

> [!IMPORTANT] Полнота пространства вещественных чисел
> Критерий Коши эквивалентен **аксиоме полноты** вещественных чисел.
