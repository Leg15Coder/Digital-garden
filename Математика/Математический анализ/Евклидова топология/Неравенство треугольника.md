### Неравенство треугольника

==Утв.== В евклидовом пространстве $\mathbb{R}^d$:$$\forall x, y \in \mathbb{R}^d\ :\ |x + y| \le |x| + |y|$$

#### Доказательство
По [[Неравенство Коши-Буняковского-Шварца|неравенству КБШ]]:$$|x + y|^2 = (x + y, x + y) = |x|^2 + 2(x, y) + |y|^2 \le |x|^2 + 2|x| \cdot |y| + |y|^2 = (|x| + |y|)^2$$Извлекая корень из обеих частей, получаем $|x + y| \le |x| + |y|$.

### Обратное неравенство треугольника

==Утв.== В $\mathbb{R}^d$:$$\forall x, y \in \mathbb{R}^d\ :\ \big||x| - |y|\big| \le |x - y|$$

#### Доказательство
1. По прямому неравенству $\triangle$-ка:$$|x| = |(x - y) + y| \le |x - y| + |y| \implies |x| - |y| \le |x - y|$$
2. Меняя местами $x$ и $y$, аналогично получаем:$$|y| - |x| \le |y - x| = |x - y|$$
3. Объединяя оба неравенства: $\big||x| - |y|\big| \le |x - y|$.
