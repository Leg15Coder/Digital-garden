### Свойства радиуса сходимости

Пусть даны [[Степенные ряды и круг сходимости|степенные ряды]] $\sum\limits_{k=0}^\infty a_k z^k$ и $\sum\limits_{k=0}^\infty b_k z^k$.

==Утв.== Если $a_n \sim b_n$ при $n \to \infty$, то $R_{\text{сх}}\left(\sum\limits_{k=0}^\infty a_k z^k\right) = R_{\text{сх}}\left(\sum\limits_{k=0}^\infty b_k z^k\right)$.

#### Доказательство
Из $a_n \sim b_n$ следует $a_n = r_n b_n$, где $r_n \xrightarrow[n \to \infty]{} 1$. Тогда $\lim\limits_{n \to \infty} \sqrt[n]{|r_n|} = \lim\limits_{n \to \infty} e^{\frac{1}{n} \ln |r_n|} = e^0 = 1$, откуда по формуле Коши-Адамара:$$\frac{1}{R_{\text{сх}}(a)} = \varlimsup\limits_{n \to \infty} \sqrt[n]{|a_n|} = \left(\lim\limits_{n \to \infty} \sqrt[n]{|r_n|}\right) \cdot \varlimsup\limits_{n \to \infty} \sqrt[n]{|b_n|} = \frac{1}{R_{\text{сх}}(b)}$$

==Утв.== Пусть $R_{\text{сх}}\left(\sum\limits_{k=0}^\infty a_k z^k\right) = R_1$ и $R_{\text{сх}}\left(\sum\limits_{k=0}^\infty b_k z^k\right) = R_2$. Тогда:$$R_{\text{сх}}\left(\sum\limits_{k=0}^\infty (a_k + b_k) z^k\right) \ge \min(R_1, R_2)$$причём если $R_1 \neq R_2$, то $R_{\text{сх}}\left(\sum\limits_{k=0}^\infty (a_k + b_k) z^k\right) = \min(R_1, R_2)$.

#### Доказательство
1. Для $\forall |z| < R_- = \min(R_1, R_2)$ оба ряда сходятся, следовательно сходится и их сумма $\sum\limits_{k=0}^\infty (a_k + b_k)z^k$, значит $R_{\text{сх}} \ge R_-$.
2. Пусть $R_1 \neq R_2$ и $R_+ = \max(R_1, R_2)$. Для $\forall z$ с $R_- < |z| < R_+$ один из рядов сходится, а другой расходится $\implies$ их сумма расходится. Для $|z| \ge R_+$ сумма не может сходиться по 1-й Т. Абеля (иначе бы ряд сходился и в точке $z_1$ с $R_- < |z_1| < R_+$). Значит $R_{\text{сх}} = R_-$.

### Почленное дифференцирование и интегрирование степенных рядов

==Опр.== **Формально продифференцированный степенной ряд**: $\sum\limits_{n=1}^\infty n a_n z^{n-1}$. **Формально проинтегрированный степенной ряд**: $\sum\limits_{n=0}^\infty \frac{a_n}{n+1} z^{n+1}$.

==Утв.== Радиус сходимости не меняется при формальном дифференцировании и формальном интегрировании:$$R_{\text{сх}}\left(\sum\limits_{n=0}^\infty a_n z^n\right) = R_{\text{сх}}\left(\sum\limits_{n=1}^\infty n a_n z^{n-1}\right) = R_{\text{сх}}\left(\sum\limits_{n=0}^\infty \frac{a_n}{n+1} z^{n+1}\right)$$

#### Доказательство
1. Перепишем продифференцированный ряд как $\sum\limits_{n=0}^\infty (n+1)a_{n+1} z^n$. Т.к. $\lim\limits_{n \to \infty} \sqrt[n]{n+1} = 1$ и $\left(\sqrt[n+1]{|a_{n+1}|}\right)^{\frac{n+1}{n}}$ имеет тот же верхний предел, что $\sqrt[n]{|a_n|}$:$$\frac{1}{R_1} = \varlimsup\limits_{n \to \infty} \sqrt[n]{(n+1)|a_{n+1}|} = \left(\lim\limits_{n \to \infty} \sqrt[n]{n+1}\right) \varlimsup\limits_{n \to \infty} \sqrt[n]{|a_{n+1}|} = \varlimsup\limits_{n \to \infty} \sqrt[n]{|a_n|} = \frac{1}{R_{\text{сх}}}$$
2. Аналогично для проинтегрированного ряда $\sum\limits_{n=1}^\infty \frac{a_{n-1}}{n} z^n$: $\varlimsup\limits_{n \to \infty} \sqrt[n]{\frac{|a_{n-1}|}{n}} = \varlimsup\limits_{n \to \infty} \sqrt[n]{|a_n|} = \frac{1}{R_{\text{сх}}}$.

==Опр.== **Интервал сходимости** вещественного степенного ряда $\sum\limits_{n=0}^\infty a_n (x - x_0)^n$ - пересечение круга сходимости с вещественной прямой: $(x_0 - R_{\text{сх}}; x_0 + R_{\text{сх}})$ *(или $(-R_{\text{сх}}; R_{\text{сх}})$ при $x_0 = 0$)*.

==Утв.== Внутри интервала сходимости сумма вещественного степенного ряда бесконечно дифференцируема и бесконечно интегрируема, причём дифференцировать и интегрировать ряд можно почленно любое число раз.

#### Доказательство
1. Для произвольного отрезка $[x_0 - r; x_0 + r]$ ($0 < r < R_{\text{сх}}$) формально продифференцированный ряд имеет тот же радиус сходимости $R_{\text{сх}}$, поэтому по 1-й Т. Абеля сходится на $[x_0 - r; x_0 + r]$ равномерно. По [[Почленное дифференцирование функциональных рядов|Т. о почленном дифференцировании]] сумма дифференцируема на $(x_0 - r; x_0 + r)$ и её производная равна сумме производных. Индукцией по порядку производной получаем $C^\infty$ и почленное дифференцирование любого порядка на всём интервале $(x_0 - R_{\text{сх}}; x_0 + R_{\text{сх}})$.
2. Для $\forall x \in (x_0 - R_{\text{сх}}; x_0 + R_{\text{сх}})$ ряд сходится равномерно на отрезке между $x_0$ и $x$ по 1-й Т. Абеля, откуда по [[Почленное интегрирование функциональных рядов|Т. о почленном интегрировании]] $\int\limits_{x_0}^x \sum\limits_{n=0}^\infty a_n (t - x_0)^n\,dt = \sum\limits_{n=0}^\infty \frac{a_n}{n+1}(x - x_0)^{n+1}$ (и по индукции для кратного интегрирования).
