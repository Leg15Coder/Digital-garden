### Мнимая и комплексная экспонента

1. Для $x \in \mathbb{R}$ (см. [[Вещественно-аналитические функции|вещественно-аналитические функции]]):$$e^x = \sum\limits_{k=0}^\infty \frac{x^k}{k!}$$
2. Для $y \in \mathbb{R}$ по определению **формулы Эйлера**:$$e^{iy} = \cos y + i\sin y = \sum\limits_{k=0}^\infty (-1)^k \frac{y^{2k}}{(2k)!} + i\sum\limits_{k=0}^\infty (-1)^k \frac{y^{2k+1}}{(2k+1)!} = \sum\limits_{k=0}^\infty \frac{(iy)^{2k}}{(2k)!} + \sum\limits_{k=0}^\infty \frac{(iy)^{2k+1}}{(2k+1)!} = \sum\limits_{k=0}^\infty \frac{(iy)^k}{k!}$$
3. Для $z = x + iy \in \mathbb{C}$, используя абсолютную сходимость обоих рядов и [[Произведение Коши рядов|Т. Коши о произведении рядов]] + бином Ньютона:$$e^z = e^x \cdot e^{iy} = \sum\limits_{n=0}^\infty \sum\limits_{k + \ell = n} \frac{x^k (iy)^\ell}{k!\,\ell!} = \sum\limits_{n=0}^\infty \frac{1}{n!} \sum\limits_{k=0}^n C_n^k x^k (iy)^{n-k} = \sum\limits_{n=0}^\infty \frac{(x + iy)^n}{n!} = \sum\limits_{n=0}^\infty \frac{z^n}{n!}$$
