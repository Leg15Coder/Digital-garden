Пусть $U \subset \mathbb{R}^n$ открыто и $f: U \to \mathbb{R}^m$.

### Основные определения

==Опр.== Функция $f$ **дифференцируема в т. $x \in U$**, если $\exists A \in Mat_{m \times n}(\mathbb{R})$ т.ч.:$$f(x + h) = f(x) + Ah + o(|h|), \quad h \xrightarrow[\mathbb{R}^n]{} 0$$Матрица $A = Df(x)$ называется **матрицей Якоби** отображения $f$ в т. $x$, а линейное отображение $h \mapsto Df(x)h$ - **дифференциалом** $df(x)$.

==Опр.== Запись $g(h) = o(|h|)$ при $h \to 0$ означает:$$\forall \varepsilon > 0\ \exists \delta > 0\ \forall h \in \mathring{U}_\delta(0) \subset \mathbb{R}^n\ :\ |g(h)| < \varepsilon |h|$$*(и $g(0) = 0$; аналогично $g = o(|f|)$)*.

==Опр.== **Частная производная** $i$-й компоненты $f_i$ по $j$-й переменной в т. $x \in U$:$$\frac{\partial f_i}{\partial x_j}(x) = \lim\limits_{t \to 0} \frac{f_i(x + t e_j) - f_i(x)}{t}$$где $e_j = (0, \dots, 1, \dots, 0)^T$ ($e_{ji} = \delta_{ij}$) - $j$-й стандартный базисный вектор $\mathbb{R}^n$.

### Необходимые условия дифференцируемости

Если $f: U \to \mathbb{R}^m$ дифференцируема в т. $x \in U$, то:
1. $f$ непрерывна в т. $x$;
2. $\forall i \in \overline{1, m}\ \forall j \in \overline{1, n}\ \exists \frac{\partial f_i}{\partial x_j}(x) \in \mathbb{R}$, причём матрица Якоби $Df(x) = (a_{ij})$ задаётся формулой $a_{ij} = \frac{\partial f_i}{\partial x_j}(x)$.

#### Доказательство
1. По определению дифференцируемости $f(x + h) - f(x) = Ah + o(|h|)$. По [[Неравенство Коши-Буняковского-Шварца|неравенству КБШ]] для каждой компоненты $(Ah)_i = \sum\limits_{j=1}^n a_{ij} h_j$:$$|(Ah)_i|^2 = \left|\sum\limits_{j=1}^n a_{ij} h_j\right|^2 \le \left(\sum\limits_{j=1}^n a_{ij}^2\right) |h|^2 \implies |Ah| = \sqrt{\sum\limits_{i=1}^m (Ah)_i^2} \le \underbrace{\sqrt{\sum\limits_{i=1}^m \sum\limits_{j=1}^n a_{ij}^2}}_{C} \cdot |h|$$Следовательно, $|f(x + h) - f(x)| \le |Ah| + |o(|h|)| \le C|h| + |o(|h|)| \xrightarrow[h \to 0]{} 0 \implies f$ непрерывна в т. $x$.
2. Подставим $h = t e_j$ ($|e_j| = 1$, $|t e_j| = |t|$):$$f(x + t e_j) - f(x) = t (A e_j) + o(|t|)$$Покомпонентно: $\forall i \in \overline{1, m}\ :\ f_i(x + t e_j) - f_i(x) = t a_{ij} + o(|t|) \implies \lim\limits_{t \to 0} \frac{f_i(x + t e_j) - f_i(x)}{t} = a_{ij}$, т.е. $\frac{\partial f_i}{\partial x_j}(x) = a_{ij}$.

### Представление $o(|h|)$

==Утв.== Для функции $\varphi: U_\delta(0) \to \mathbb{R}$ ($h = (h_1, \dots, h_n)^T \in \mathbb{R}^n$):$$\varphi(h) = o(|h|), \ h \to 0 \iff \varphi(h) = \sum\limits_{i=1}^n \alpha_i(h) h_i, \quad \text{где } \forall i \in \overline{1, n}\ :\ \alpha_i(h) \xrightarrow[h \to 0]{} 0$$

#### Доказательство
1. ($\Leftarrow$) По неравенству КБШ (или $|h_i| \le |h|$): $|\varphi(h)| \le \sum\limits_{i=1}^n |\alpha_i(h)| \cdot |h_i| \le \left(\sum\limits_{i=1}^n |\alpha_i(h)|\right)|h| = o(|h|)$, т.к. $\sum\limits_{i=1}^n |\alpha_i(h)| \xrightarrow[h \to 0]{} 0$.
2. ($\Rightarrow$) По определению $\varphi(h) = \alpha(h)|h|$ при $h \neq 0$, где $\alpha(h) \xrightarrow[h \to 0]{} 0$. Домножая и деля на $|h|$ (используя $|h|^2 = \sum\limits_{i=1}^n h_i^2$):$$\varphi(h) = \alpha(h) \frac{|h|^2}{|h|} = \sum\limits_{i=1}^n \underbrace{\left(\alpha(h) \frac{h_i}{|h|}\right)}_{\alpha_i(h)} h_i$$Т.к. $\left|\frac{h_i}{|h|}\right| \le 1$, имеем $|\alpha_i(h)| \le |\alpha(h)| \xrightarrow[h \to 0]{} 0$ (и $\alpha_i(0) = 0$).
