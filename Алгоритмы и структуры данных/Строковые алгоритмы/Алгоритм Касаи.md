### Цель и проблематизация

Суффиксный массив $P$ кодирует лексикографический порядок всех суффиксов строки $S$. Однако сам по себе суффиксный массив не позволяет быстро отвечать на запросы о длине наибольшего общего префикса произвольных подстрок, находить количество различных подстрок или выполнять эффективный поиск шаблона за $O(m + \log n)$.

Для решения этих задач используется массив наибольших общих префиксов соседних суффиксов - **массив LCP** *(Longest Common Prefix)*. Наивный расчёт массива LCP требует $O(n^2)$ операций. **Алгоритм Касаи** *(Kasai's algorithm)* позволяет вычислить массив $lcp$ за линейное время $O(n)$, задействуя фундаментальное свойство сохранения длины общего префикса при переходе от суффикса $S[i-1:]$ к суффиксу $S[i:]$.

---

### Математическая постановка задачи и формальные определения

Пусть дана строка $S = s_0 s_1 \dots s_{n-1}$ длины $n$ над алфавитом $\Sigma$ и её суффиксный массив $P = (p_0, p_1, \dots, p_{n-1})$.

==Опр.== **Наибольший общий префикс** *(LCP)* - функция $\text{LCP}(A, B)$, возвращающая длину максимального совпадающего префикса двух строк $A$ и $B$:
$$\text{LCP}(A, B) = \max\limits_{k \ge 0} \{ k \mid A[:k] = B[:k] \}$$

==Опр.== **Обратный суффиксный массив** *(Inverse SA, массив $pos$)* - массив $pos$ длины $n$, где $pos[i]$ определяет позицию (ранг) суффикса $S[i:]$ в отсортированном суффиксном массиве $P$:$$pos[P[r]] = r \quad \forall r \in \overline{0, n-1}$$

==Опр.== **Массив LCP** - массив $lcp$ длины $n$, где $lcp[r]$ равен длине наибольшего общего префикса суффикса $S[P[r]:]$ и его предшественника $S[P[r-1]:]$ в суффиксном массиве:
$$lcp[0] = 0, \quad lcp[r] = \text{LCP}(S[P[r]:], S[P[r-1]:]) \quad \forall r \in \overline{1, n-1}$$

> [!INFO] Свойство LCP для произвольной пары суффиксов
> Длина наибольшего общего префикса для двух произвольных суффиксов с рангами $r_1 < r_2$ в суффиксном массиве равна минимуму на отрезке $[r_1 + 1, r_2]$ массива $lcp$:
> $$\text{LCP}(S[P[r_1]:], S[P[r_2]:]) = \min\limits_{k \in \overline{r_1 + 1, r_2}} lcp[k]$$

### Двухуровневое объяснение

> [!TIP] Интуиция сохранения общего префикса
> Рассмотрите два соседних в суффиксном массиве суффикса $S[i-1:]$ и $S[j:]$, имеющих общий префикс длины $k$. Если отбросить от обеих строк первый символ (который у них гарантированно совпадает), то оставшиеся суффиксы $S[i:]$ и $S[j+1:]$ будут иметь общий префикс длины не менее $k - 1$. Порядок отсортированности суффиксов гарантирует, что непосредственно предшествующий суффиксу $S[i:]$ элемент в массиве $P$ будет иметь с ним общий префикс длиной **не меньше** $k - 1$.

> [!EXAMPLE] Бытовая аналогия
> Представьте слова в словаре: "картина" и "картошка". Их общий префикс - "карт" (длина 4). Если отрезать первую букву 'к', получим слова "артина" и "артошка", чей общий префикс равен "арт" (длина $4 - 1 = 3$). Какое бы слово ни стояло в словаре непосредственно перед "артина", оно обязано совпадать с ней минимум в 3 первых буквах ("арт").

## Алгоритм Касаи

> [!important] Цель
> Построение массива $lcp$ длины $n$ за время $O(n)$ при известных строке $S$ и суффиксном массиве $P$.

### 1. Алгоритм

1) **Построение обратного массива $pos$:**
   Для каждого $r$ от $0$ до $n-1$ положить $pos[P[r]] = r$.
2) **Инициализация:**
   Создать массив $lcp$ длины $n$. Положить текущую длину префикса $k = 0$.
3) **Итеративный расчёт в порядке убывания длин суффиксов:**
   Для каждого индекса $i$ от $0$ до $n-1$:
   3.1) Найти ранг текущего суффикса: $r = pos[i]$.
   3.2) Если $r == 0$, положить $lcp[0] = 0$, сбросить $k = 0$ и перейти к следующей итерации.
   3.3) Определить индекс предшествующего суффикса в массиве $P$: $j = P[r - 1]$.
   3.4) **Наивный дорасчёт префикса:** Пока $i + k < n$, $j + k < n$ и $S[i + k] == S[j + k]$, инкрементировать $k = k + 1$.
   3.5) Записать результат: $lcp[r] = k$.
   3.6) Если $k > 0$, уменьшить параметр на единицу для следующего шага: $k = k - 1$.
4) Вернуть массив $lcp$.

```python
def build_lcp_kasai(s: str, p: list[int]) -> list[int]:
    n = len(s)
    pos = [0] * n
    for r in range(n):
        pos[p[r]] = r

    lcp = [0] * n
    k = 0

    for i in range(n):
        r = pos[i]
        if r == 0:
            lcp[0] = 0
            k = 0
            continue

        j = p[r - 1]
        while i + k < n and j + k < n and s[i + k] == s[j + k]:
            k += 1

        lcp[r] = k
        if k > 0:
            k -= 1

    return lcp

```

### 2. Асимптотика

* **Временная сложность:**
1. Внешний цикл `for` выполняется ровно $n$ раз.
2. Значение переменной $k$ на каждом шаге внешнего цикла уменьшается максимум на $1$ (в блоке `if k > 0: k -= 1`).
3. Поскольку $k \le n$, суммарно за весь алгоритм значение $k$ может уменьшиться не более чем $n$ раз.
4. Внутренний цикл `while` только увеличивает $k$. Следовательно, суммарное число итераций цикла `while` за весь прогон алгоритма не превосходит $2n$.
5. Итоговая временная сложность составляет строго $O(n)$.


* **Пространственная сложность:** $O(n)$ для хранения обратного массива $pos$ и результирующего массива $lcp$.

### 3. Математическое доказательство

#### Лемма *(Об оценке снизу для LCP соседних суффиксов)*

$$\forall i \in \overline{1, n-1} \ : \ lcp[pos[i]] \ge lcp[pos[i-1]] - 1$$

#### Доказательство

1. Обозначим $r = pos[i-1]$ (ранг суффикса $S[i-1:]$). Если $lcp[r] \le 1$, неравенство $lcp[pos[i]] \ge lcp[r] - 1$ выполняется тривиально, т.к. $lcp \ge 0$.
2. Пусть $k = lcp[r] > 1$. Рассмотрите суффикс $S[j:]$, предшествующий $S[i-1:]$ в массиве $P$ ($pos[j] = r - 1$). По определению:

$$\text{LCP}(S[i-1:], S[j:]) = k > 1$$


3. Поскольку первые символы совпадают ($S[i-1] = S[j]$), отбросим их. Для суффиксов $S[i:]$ и $S[j+1:]$ справедливо:

$$\text{LCP}(S[i:], S[j+1:]) = k - 1$$


4. Поскольку $S[j:] < S[i-1:]$, отбрасывание первого символа сохраняет лексикографический порядок: $S[j+1:] < S[i:]$.
5. В отсортированном суффиксном массиве $P$ суффикс $S[j+1:]$ расположен строго раньше $S[i:]$, т.е. $pos[j+1] < pos[i]$.
6. По свойствам суффиксного массива, для любого суффикса $S[x:]$, расположенного в $P$ между $S[j+1:]$ и $S[i:]$, выполняется:

$$\text{LCP}(S[x:], S[i:]) \ge \text{LCP}(S[j+1:], S[i:]) = k - 1$$


7. В частности, для непосредственного предшественника суффикса $S[i:]$ в массиве $P$ (имеющего индекс $P[pos[i]-1]$):

$$lcp[pos[i]] = \text{LCP}(S[P[pos[i]-1]:], S[i:]) \ge k - 1 = lcp[pos[i-1]] - 1$$



Лемма доказана. Из леммы следует корректность пропуска первых $k-1$ символов алгоритмом Касаи. $\blacksquare$

### 4. Пример применения

Пусть $S = \text{"aaba"}$, $n = 4$.

1. **Суффиксный массив $P$ и $pos$:**
* $S[0:] = \text{"aaba"}$
* $S[1:] = \text{"aba"}$
* $S[2:] = \text{"ba"}$
* $S[3:] = \text{"a"}$


Отсортированный порядок $P = [3, 0, 1, 2]$:
* $P[0] = 3 \implies \text{"a"}$
* $P[1] = 0 \implies \text{"aaba"}$
* $P[2] = 1 \implies \text{"aba"}$
* $P[3] = 2 \implies \text{"ba"}$


Обратный массив $pos = [1, 2, 3, 0]$.
2. **Исполнение алгоритма Касаи:**
* $i = 0$ ($S[0:] = \text{"aaba"}$):
* $r = pos[0] = 1$. Предшественник $P[0] = 3$ ($S[3:] = \text{"a"}$).
* Сравнение $\text{"aaba"}$ и $\text{"a"}$: $S[0] == S[3] \implies k = 1$.
* $lcp[1] = 1$. Обновление $k = 1 - 1 = 0$.


* $i = 1$ ($S[1:] = \text{"aba"}$):
* $r = pos[1] = 2$. Предшественник $P[1] = 0$ ($S[0:] = \text{"aaba"}$).
* $k$ заходит равным $0$. Сравнение $\text{"aba"}$ и $\text{"aaba"}$: $S[1] == S[0] \implies k = 1$.
* $lcp[2] = 1$. Обновление $k = 1 - 1 = 0$.


* $i = 2$ ($S[2:] = \text{"ba"}$):
* $r = pos[2] = 3$. Предшественник $P[2] = 1$ ($S[1:] = \text{"aba"}$).
* $k$ заходит равным $0$. Сравнение $\text{"ba"}$ и $\text{"aba"}$: $S[2] \neq S[1] \implies k = 0$.
* $lcp[3] = 0$. Обновление $k = 0$.


* $i = 3$ ($S[3:] = \text{"a"}$):
* $r = pos[3] = 0 \implies lcp[0] = 0$.




3. **Итоговый массив $lcp$:** $[0, 1, 1, 0]$.
