### Цель и проблематизация

Рассматривается задача точного поиска всех вхождений множества образцов (паттернов) $\mathcal{P} = \{P_1, P_2, \dots, P_k\}$ совокупной длины $M = \sum\limits_{i=1}^k \vert{}P_i\vert{}$ в текст $T$ длины $n$[cite: 28]. Последовательный запуск алгоритма КМП для каждого паттерна по отдельности требует $O\left(\sum\limits_{i=1}^k (\vert{}T\vert{} + \vert{}P_i\vert{})\right) = O(k \cdot n + M)$ операций[cite: 28]. При большом количестве слов $k$ данный подход становится неэффективным[cite: 28].

Алгоритм Ахо-Корасик строит детерминированный конечный автомат (ДКА) на префиксном дереве (боре) за время $O(M \cdot \vert{}\Sigma\vert{})$[cite: 28], что позволяет просканировать текст $T$ за один проход за время $O(n + K_{\text{out}})$, где $K_{\text{out}}$ - суммарное количество найденных вхождений. Применение сжатых суффиксных ссылок избавляет алгоритм от холостых обходов нетерминальных вершин при сборе результатов.

### Математическая постановка задачи и формальные определения

Пусть $\Sigma$ - алфавит мощности $\vert{}\Sigma\vert{}$, $\mathcal{P} = \{P_1, P_2, \dots, P_k\}$ - набор паттернов[cite: 28], $T$ - текст длины $n$[cite: 28].
Префиксное дерево (бор) $A = (V, E)$ построено на словах из $\mathcal{P}$, где $r \in V$ - корень бора (пустая строка $\epsilon$).

==Опр.== **Суффиксная ссылка** *(suffix link)* - отображение $\text{link}: V \to V$, сопоставляющее вершине $u$ такую вершину $v = \text{link}(u)$, что строка $w(v)$ является наибольшим собственным суффиксом строки $w(u)$, существующим в боре $A$ в качестве префикса какого-либо паттерна из $\mathcal{P}$.

==Опр.== **Сжатая суффиксная ссылка** *(терминальная ссылка, comp link / exit link)* - отображение $\text{comp}: V \to V \cup \{\emptyset\}$, определяемое рекуррентно[cite: 28] :
$$\text{comp}(u) = \begin{cases} \text{link}(u), & \text{если } \text{link}(u) \text{ терминальная}[cite: 28] \\ \text{comp}(\text{link}(u)), & \text{иначе}[cite: 28] \end{cases}$$

==Опр.== **Автоматная функция перехода** - отображение $\delta: V \times \Sigma \to V$, вычисляемое для вершины $u$ и символа $c \in \Sigma$ :
$$\delta(u, c) = \begin{cases} v, & \text{если } (u, v) \in E \text{ с меткой } c \\ \delta(\text{link}(u), c), & \text{если } (u, v) \notin E \land u \neq r \\ r, & \text{если } (u, v) \notin E \land u = r \end{cases}$$

> [!INFO] Геометрическая интуиция сжатых ссылок
> Обычная суффиксная ссылка $\text{link}(u)$ показывает наибольший супрефикс. Однако соответствующая вершина может не являться концом ни одного из паттернов (быть нетерминальной). Чтобы не тратить время на последовательные переходы $\text{link}(u) \to \text{link}(\text{link}(u)) \to \dots$ в поисках совпадений, сжатая ссылка $\text{comp}(u)$ "пробрасывает" указатель строго на ближайшую терминальную вершину в этой цепи[cite: 28].

## Поиск множества паттернов в тексте (Алгоритм Ахо-Корасик)

> [!important] Цель
> Поиск всех вхождений множества паттернов $P_1, \dots, P_k$ в текст $T$ за время $O(n + K_{\text{out}})$ после однократного построения автомата[cite: 28].

### 1. Алгоритм

#### Алгоритм

1) **Построение бора:** Построить префиксное дерево $A = (V, E)$ для множества образцов $\mathcal{P} = \{P_1, \dots, P_k\}$[cite: 28].
2) **Построение переходов и суффиксных ссылок (BFS):**
   2.1) Инициализировать очередь $Q$. Положить $\text{link}(r) = r$, $\text{comp}(r) = \emptyset$.
   2.2) Для каждого $c \in \Sigma$: если есть ребро $(r, u)$ с меткой $c$, то $\delta(r, c) = u$, $\text{link}(u) = r$, $\text{comp}(u) = \emptyset$, добавить $u$ в $Q$; иначе $\delta(r, c) = r$.
   2.3) Пока очередь $Q$ не пуста:
        - Извлечь $u = Q.\text{pop}()$.
        - **Вычисление сжатой ссылки:** Если $\text{link}(u).\text{is\_terminal} == \text{True}$, положить $\text{comp}(u) = \text{link}(u)$[cite: 28]. Иначе $\text{comp}(u) = \text{comp}(\text{link}(u))$[cite: 28].
        - Для каждого $c \in \Sigma$: если есть ребро $(u, v)$ с меткой $c$, положить $\text{link}(v) = \delta(\text{link}(u), c)$, $\delta(u, c) = v$, добавить $v$ в $Q$; иначе положить $\delta(u, c) = \delta(\text{link}(u), c)$.
3) **Поиск в тексте $T$:**
   3.1) Установить текущую вершину $u = r$.
   3.2) Для каждого символа $T[i]$ ($i \in \overline{0, n-1}$):
        - Совершить автоматный переход: $u = \delta(u, T[i])$.
        - **Сбор совпадений через сжатые ссылки:**
          Установить $v = u$.
          Пока $v \neq \emptyset$:
          - Если $v.\text{is\_terminal} == \text{True}$, зафиксировать вхождение паттерна $w(v)$ с окончанием в позиции $i$ текста $T$.
          - Перейти к следующей терминальной вершине: $v = \text{comp}(v)$.
4) Вернуть список всех найденных позиций вхождений.

```python
from collections import deque

class Node:
    def __init__(self):
        self.children = {}      # Исходные рёбра бора
        self.go = {}            # Автоматная функция перехода \delta(u, c)
        self.link = None        # Суффиксная ссылка
        self.comp = None        # Сжатая суффиксная ссылка
        self.is_terminal = False
        self.pattern_ids = []   # Список ID паттернов, завершающихся в узле

class AhoCorasick:
    def __init__(self, patterns: list[str], alphabet: list[str]):
        self.root = Node()
        self.alphabet = alphabet
        self._build_trie(patterns)
        self._build_automaton()

    def _build_trie(self, patterns: list[str]):
        for pid, pattern in enumerate(patterns):
            curr = self.root
            for char in pattern:
                if char not in curr.children:
                    curr.children[char] = Node()
                curr = curr.children[char]
            curr.is_terminal = True
            curr.pattern_ids.append(pid)

    def _build_automaton(self):
        queue = deque()
        self.root.link = self.root
        self.root.comp = None

        # Инициализация корня
        for c in self.alphabet:
            if c in self.root.children:
                child = self.root.children[c]
                self.root.go[c] = child
                child.link = self.root
                child.comp = None
                queue.append(child)
            else:
                self.root.go[c] = self.root

        # BFS по узлам бора
        while queue:
            u = queue.popleft()

            # Подсчёт сжатой суффиксной ссылки comp(u)
            if u.link.is_terminal:
                u.comp = u.link
            else:
                u.comp = u.link.comp

            # Переходы для сыновей
            for c in self.alphabet:
                if c in u.children:
                    v = u.children[c]
                    v.link = u.link.go[c]
                    u.go[c] = v
                    queue.append(v)
                else:
                    u.go[c] = u.link.go[c]

    def search(self, text: str) -> list[tuple[int, int]]:
        results = []
        curr = self.root

        for i, char in enumerate(text):
            curr = curr.go.get(char, self.root)
            temp = curr
            while temp is not None:
                if temp.is_terminal:
                    for pid in temp.pattern_ids:
                        results.append((pid, i))
                temp = temp.comp
        return results

```

#### Асимптотика

* **Временная сложность:**
1. *Построение бора:* $O(M)$, где $M = \sum |P_i|$.
2. *Построение автомата (BFS):* $O(|V| \cdot |\Sigma|) = O(M \cdot |\Sigma|)$.


3. *Сканирование текста:* Каждая итерация цикла по тексту $T$ выполняет ровно $1$ автоматный переход за $O(1)$. Сбор совпадений по цепи `comp` совершает итерации только по терминальным вершинам, требуя $O(1)$ времени на каждое реально найденное вхождение. Суммарное время сканирования составляет $O(n + K_{\text{out}})$.
4. *Итоговая временная сложность:* $T(n, M) = O(M \cdot |\Sigma| + n + K_{\text{out}})$.




* **Пространственная сложность:** Хранение автомата $\delta$, таблиц переходов, `link` и `comp` для всех вершин требует $O(M \cdot |\Sigma|)$ памяти.



#### Корректность

Доказательство проводится по индукции по позиции $i$ в тексте $T$.

* **База ($i = 0$):** До начала обработки текста состояние $u = r$ (корень). Пустая строка корректно соответствует нулевому префиксу.
* **Индукционное предположение:** Пусть после чтения префикса $T[:i]$ текущая вершина $u$ соответствует наибольшему суффиксу $T[:i]$, являющемуся префиксом некоторого паттерна из $\mathcal{P}$.
* **Шаг индукции:** При прочтении символа $T[i]$ выполняется переход $u' = \delta(u, T[i])$.
1. По построению автоматной функции $\delta$, переход $\delta(u, c)$ равносилен движению по рёбрам бора или последовательному откату по суффиксным ссылкам до первого узла, имеющего ребро $c$. По свойствам суффиксных ссылок полученный узел $u'$ отвечает максимальному суффиксу $T[:i+1]$, существующему в боре.
2. Переход по цепи `comp(u')` обойдёт ровно те и только те вершины $v$, строки которых $w(v)$ являются суффиксами $w(u')$, помеченными как терминальные ($v.\text{is\_terminal} == \text{True}$).
3. Поскольку все суффиксы $w(u')$ также являются суффиксами $T[:i+1]$, этот переход найдёт абсолютно все паттерны, оканчивающиеся точно в позиции $i$ текста $T$. Корректность доказана.



#### Пример применения

Пусть $\mathcal{P} = \{P_1 = \text{"he"}, P_2 = \text{"she"}, P_3 = \text{"his"}\}$, текст $T = \text{"ushers"}$.

1. Построение бора:
* Корень $r = \epsilon$.
* Узлы: $v_h (\text{"h"}), v_{he} (\text{"he"}, \text{term}=1), v_s (\text{"s"}), v_{sh} (\text{"sh"}), v_{she} (\text{"she"}, \text{term}=2), v_{hi} (\text{"hi"}), v_{his} (\text{"his"}, \text{term}=3)$.


2. Вычисление ссылок `link` и `comp`:
* $\text{link}(v_{sh}) = v_h$.
* $\text{link}(v_{she}) = v_{he}$ (терминальная!).
* По формуле: $\text{comp}(v_{she}) = \text{link}(v_{she}) = v_{he}$.




3. Обработка текста $T = \text{"ushers"}$:
* $i = 0, T[0] = \text{'u'} \implies u = r$.
* $i = 1, T[1] = \text{'s'} \implies u = v_s$.
* $i = 2, T[2] = \text{'h'} \implies u = v_{sh}$.
* $i = 3, T[3] = \text{'e'} \implies u = v_{she}$.
* $v_{she}.\text{is\_terminal} == \text{True} \implies$ вхождение $P_2 = \text{"she"}$ на позиции $3$.
* Переход по сжатой ссылке: $v = \text{comp}(v_{she}) = v_{he}$.


* $v_{he}.\text{is\_terminal} == \text{True} \implies$ вхождение $P_1 = \text{"he"}$ на позиции $3$.
* $\text{comp}(v_{he}) = \emptyset \implies$ переход завершён.
