Пусть дана строка $S = s_0 s_1 \dots s_{n-1}$ длины $n$ над алфавитом $\Sigma$. Обозначим $S[:i+1]$ префикс строки $S$ длины $i + 1$.

==Опр.== **Супрефикс** *(бордер)* - подстрока $T$, одновременно являющаяся префиксом и суффиксом строки $S$.

==Опр.== **Собственный супрефикс** - супрефикс $T$ строки $S$, не совпадающий со всей строкой $S$ ($\vert{}T\vert{} < \vert{}S\vert{}$).

==Опр.== **Префикс-функция** *( $\pi$-функция )* - массив $\pi$ длины $n$, где $\pi[i]$ равен длине максимального собственного супрефикса подстроки $S[:i+1]$.

Математически значение $\pi[i]$ задаётся выражением:$$\pi[i] = \max\limits_{k \in \overline{0,i}} \{ k \mid S[:k] = S[i-k+1:i+1] \}$$По определению полагается $\pi[0] = 0$, так как у подстроки длины 1 единственный супрефикс совпадает со всей строкой и не является собственным.

> [!INFO] Геометрический смысл
> Значение $\pi[i]$ показывает длину наибольшего совмещения начала строки $S$ с её хвостом, заканчивающимся в позиции $i$. Массив $\pi$ кодирует внутреннюю самоподобность структуры строки.

> [!TIP] Интуиция сдвига при несовпадении
> Представьте, что вы сравниваете текст с шаблоном и наткнулись на расхождение в символе $S[i]$. Вы уже знаете совпавший префикс шаблона длины $k = \pi[i-1]$. Если текущий символ $S[i]$ не равен $S[k]$, нет смысла начинать поиск сначала. Нам достаточно найти следующий по величине супрефикс совпавшей части, который совпадает с новым началом шаблона. Этот следующий супрефикс находится по индексу $\pi[k-1]$. Мы повторяем эту процедуру, "прыгая" по супрефиксам, пока не найдём символ, совпадающий с $S[i]$, либо пока не упрёмся в 0.

#### [TODO] **Утв.** *(О рекуррентной структуре множества супрефиксов)*

Пусть $\mathcal{B}(S[:i])$ - множество длин собственных супрефиксов строки $S[:i]$:$$\mathcal{B}(S[:i]) = \{ k \in \overline{0, i-1} \mid S[:k] = S[i-k:i] \}$$
##### Лемма
$$\forall i \in \overline{1, n}, \ \forall k < \pi[i-1] \ : \ k \in \mathcal{B}(S[:i]) \iff k \in \mathcal{B}(S[:\pi[i-1]])$$

##### Доказательство леммы
Обозначим $L = \pi[i-1]$.

1. **Достаточность ($\Leftarrow$):**
   $$k \in \mathcal{B}(S[:L]) \implies S[:k] = S[L-k:L]$$
   По определению $L = \pi[i-1] \implies S[:L] = S[i-L:i]$.
   Сопоставляя равные подстроки :
   $$S[L-k:L] = S[i-k:i] \implies S[:k] = S[i-k:i] \implies k \in \mathcal{B}(S[:i])$$

2. **Необходимость ($\Rightarrow$):**
   $$k \in \mathcal{B}(S[:i]) \land k < L \implies S[:k] = S[i-k:i]$$
   Так как $S[:L] = S[i-L:i]$, суффикс длины $k$ строки $S[:i]$ совпадает с суффиксом длины $k$ строки $S[:L]$ :
   $$S[i-k:i] = S[L-k:L] \implies S[:k] = S[L-k:L] \implies k \in \mathcal{B}(S[:L])$$

##### Доказательство утверждения


$$\forall i \in \overline{1, n} \ : \ \mathcal{B}(S[:i]) = \{k_1, k_2, \dots, k_m\}$$
где $k_1 = \pi[i-1]$, $k_j = \pi[k_{j-1}-1]$ при $j > 1$, $k_m = 0$.
Доказательство проводится по индукции на основе выведенной Леммы.

1. **База индукции:**
   $$\pi[i-1] = 0 \implies \mathcal{B}(S[:i]) = \{0\} \implies k_1 = 0$$

2. **Шаг индукции:**
   Пусть $k_1 = \pi[i-1] > 0$. По определению $\pi[i-1]$ :
   $$k_1 = \max \mathcal{B}(S[:i])$$
   По Лемме для элементов $k < k_1$ :
   $$\mathcal{B}(S[:i]) \setminus \{k_1\} = \{k < k_1 \mid k \in \mathcal{B}(S[:i])\} = \mathcal{B}(S[:k_1])$$
   По определению префикс-функции для строки $S[:k_1]$ :
   $$\max \mathcal{B}(S[:k_1]) = \pi[k_1-1] = k_2$$
   Раскрывая рекуррентное соотношение последовательно :
   $$\mathcal{B}(S[:i]) = \{k_1\} \cup \mathcal{B}(S[:k_1]) = \{k_1, k_2\} \cup \mathcal{B}(S[:k_2]) = \dots = \{k_1, k_2, \dots, k_m\}$$
   где $k_j = \pi[k_{j-1}-1]$ и $\exists m \in \mathbb{N} \ : \ k_m = 0$.

## Алгоритм построения префикс-функции

> [!important] Цель
> Построение массива префикс-функции $\pi$ длины $n$ для заданной строки $S = s_0 s_1 \dots s_{n-1}$.

### 1. Наивный алгоритм
#### Алгоритм

1) Создать массив $\pi$ длины $n$, заполнив его нулями: $\pi[0] = 0$.
2) Для каждого индекса $i$ от $1$ до $n-1$:
	2.1) Перебрать значение $k$ (длину потенциального супрефикса) от $i$ до $1$ в порядке убывания.
	2.2) Сравнить подстроку-префикс $S[:k]$ и подстроку-суффикс $S[i-k+1:i+1]$.
	2.3) Если $S[:k] = S[i-k+1:i+1]$, положить $\pi[i] = k$ и прервать перебор по $k$ для текущего $i$.
	2.4) Если ни одно $k > 0$ не подошло, оставить $\pi[i] = 0$.
3) Вернуть заполненный массив $\pi$.

#### Асимптотика

- **Временная сложность:** Внешний цикл по $i$ выполняется $n-1$ раз. Для каждого $i$ внутренний цикл по $k$ в худшем случае делает $i$ итераций. Сравнение подстрок длины $k$ выполняется за $O(k)$ операций. Суммарная временная сложность составляет:$$T(n) = \sum\limits_{i=1}^{n-1} \sum\limits_{k=1}^{i} O(k) = \sum\limits_{i=1}^{n-1} O(i^2) = O(n^3)$$

- **Пространственная сложность:** Дополнительная память составляет $O(1)$ без учёта результирующего массива $\pi$ размера $O(n)$.

#### Корректность

По определению префикс-функции $\pi[i] = \max\limits_{k \in \overline{0,i}} \{ k \mid S[:k] = S[i-k+1:i+1] \}$. Повторяющийся перебор зафиксированного $i$ проверяет все возможные длины $k \in \overline{1, i}$ в порядке строгого убывания. Первая длина $k$, на которой выполняется равенство подстрок $S[:k] = S[i-k+1:i+1]$, гарантированно является наибольшей. Если ни одно значение $k > 0$ не удовлетворило равенству, то по определению супрефикс имеет нулевую длину, что алгоритм и фиксирует ($\pi[i] = 0$).

#### Пример применения

Пусть $S = \text{"abacaba"}$, $n = 7$.
- $i = 0$ ($S[:1] = \text{"a"}$): по определению $\pi[0] = 0$.
- $i = 1$ ($S[:2] = \text{"ab"}$):
  - $k = 1$: $S[:1] = \text{"a"} \neq S[1:2] = \text{"b"}$.
  - Итог: $\pi[1] = 0$.
- $i = 2$ ($S[:3] = \text{"aba"}$):
  - $k = 2$: $S[:2] = \text{"ab"} \neq S[1:3] = \text{"ba"}$.
  - $k = 1$: $S[:1] = \text{"a"} = S[2:3] = \text{"a"}$. Найдено соответствие.
  - Итог: $\pi[2] = 1$.
- Итоговый массив: $\pi = [0, 0, 1, 0, 1, 0, 3]$.

### 2. Линейный алгоритм
#### Алгоритм

1() Инициализировать массив $\pi$ длины $n$ нулями: $\pi[0] = 0$.
1) Для каждого $i$ от $1$ до $n-1$:
    2.1) Инициализировать переменного-кандидата $k = \pi[i-1]$.
	2.2) **Цикл перехода по супрефиксам:** Пока $k > 0$ и текущие символы не совпадают ($S[i] \neq S[k]$), уменьшать длину кандидата, переходя к следующему по величине супрефиксу: $k = \pi[k-1]$.
	2.3) **Проверка расширения:** Если $S[i] == S[k]$, увеличить длину совпавшего супрефикса на 1: $k = k + 1$.
	2.4) Записать результат: $\pi[i] = k$.
2) Вернуть массив $\pi$.

```python
def prefix_function(s: str) -> list[int]:
    n = len(s)
    pi = [0] * n
    for i in range(1, n):
        k = pi[i - 1]
        while k > 0 and s[i] != s[k]:
            k = pi[k - 1]
        if s[i] == s[k]:
            k += 1
        pi[i] = k
    return pi
````

#### Асимптотика

- **Временная сложность:** Проанализируем изменения значения переменной $k$ за всё время выполнения алгоритма:
    1. Внешний цикл `for` выполняется ровно $n-1$ раз.
    2. Значение $k$ может увеличиться максимум на $1$ за одну итерацию внешнего цикла (в блоке `if s[i] == s[k]: k += 1`). Следовательно, за весь прогон алгоритма суммарный прирост $k$ не превышает $n-1$.
    3. Внутренний цикл `while` на каждой итерации строго уменьшает значение $k$, так как $\pi[k-1] < k$.
    4. Поскольку $k \ge 0$, суммарное количество уменьшений $k$ в цикле `while` не может превышать суммарное количество его увеличений.
    5. Таким образом, цикл `while` выполнит суммарно не более $n-1$ итераций за весь алгоритм. [[Амортизационный анализ|Амортизированное время]] работы составляет $O^*(n)$.

- **Пространственная сложность:** Память под массив $\pi$ составляет $O(n)$, дополнительная память - $O(1)$.

#### Корректность

Доказательство проводится индукцией по индексу $i$.
- **База ($i = 0$):** По определению $\pi[0] = 0$, т.к. у подстроки длины 1 нет собственного супрефикса.
- **Предположение:** Пусть для $\forall$ $j < i$ значения $\pi[j]$ вычислены верно.
- **Шаг:** Докажем корректность нахождения $\pi[i]$.
    1. _Оценка сверху:_ Любой супрефикс подстроки $S[:i+1]$ длины $m > 0$ при отбрасывании последнего символа $S[i]$ образует супрефикс подстроки $S[:i]$ длины $m - 1$. Отсюда следует ограничение: $m - 1 \le \pi[i-1] \implies m \le \pi[i-1] + 1$.
    2. _Множество кандидатов:_ По свойствам супрефиксов, последовательность всех длин собственных супрефиксов строки $S[:i]$ задаётся рекуррентно: $k_1 = \pi[i-1]$, $k_2 = \pi[k_1-1]$, $k_3 = \pi[k_2-1]$ и т.д.
    3. Алгоритм последовательно проверяет эти длины $k$ в порядке строгого убывания. Если символ $S[i]$ совпадает с $S[k]$, то строка $S[:k+1]$ является супрефиксом для $S[:i+1]$ длины $k+1$. Первая найденная такая длина по индукционному предположению является максимальной. Корректность доказана.

#### Пример применения

Пусть $S = \text{"aabaa"}$, $n = 5$.
- $i = 0$: $\pi[0] = 0$.
- $i = 1$ ($S[1] = \text{'a'}$):
    - $k = \pi[0] = 0$. Символы $S[1] == S[0]$ ('a' == 'a').
    - $k = k + 1 = 1 \implies \pi[1] = 1$
- $i = 2$ ($S[2] = \text{'b'}$):
    - $k = \pi[1] = 1$. Символы $S[2] \neq S[1]$ ('b' $\neq$ 'a').
    - Переход: $k = \pi[k-1] = \pi[0] = 0$.
    - Символы $S[2] \neq S[0]$ ('b' $\neq$ 'a').
    - Итог: $\pi[2] = 0$.
- $i = 3$ ($S[3] = \text{'a'}$):
    - $k = \pi[2] = 0$. Символы $S[3] == S[0]$ ('a' == 'a').
    - $k = k + 1 = 1 \implies \pi[3] = 1$.
- $i = 4$ ($S[4] = \text{'a'}$):
    - $k = \pi[3] = 1$. Символы $S[4] == S[1]$ ('a' == 'a').
    - $k = k + 1 = 2 \implies \pi[4] = 2$.
- Итоговый массив: $\pi = [0, 1, 0, 1, 2]$.
