### Цель и проблематизация

При анализе подстрок строки $S$ длины $n$ наивные структуры данных (например, Бор всех подстрок) требуют $O(n^2)$ памяти. Суффиксное дерево решает проблему памяти за счёт сжатия путей до $O(n)$, но обладает высокой сложностью реализации.

**Суффиксный автомат** *(Suffix Automaton, SAM, DAWG)* представляет собой минимальный ориентированный детерминированный конечный автомат, распознающий множество всех суффиксов строки $S$. Конструкция SAM сжимает эквивалентные по правому контексту подстроки в единые состояния, обеспечивая границу количества состояний $|V| \le 2n - 1$ и переходов $|E| \le 3n - 4$. Это позволяет отвечать на задачи поиска подстрок, подсчёта уникальных подстрок и анализа повторов за линейное время $O(n)$.

---

### 1. Правые контексты и формальные определения

Пусть $S = s_0 s_1 \dots s_{n-1}$ - строка длины $n$ над алфавитом $\Sigma$. Для любой подстроки $x$ строки $S$ определим множество её позиций окончаний.

==Опр.== **Правый контекст подстроки** *(множество Endpos)* - множество всех индексов окончаний вхождений подстроки $x$ в строку $S$:
$$\text{Endpos}(x) = \{ i \in \overline{0, n-1} \mid S[i - |x| + 1 \dots i] = x \}$$

==Опр.== **Эквивалентность по Майхиллу-Нероуду** - две подстроки $x$ и $y$ эквивалентны ($x \sim_S y$), если совпадают множества их правых контекстов:
$$x \sim_S y \iff \text{Endpos}(x) = \text{Endpos}(y)$$

==Опр.== **Суффиксный автомат** *(SAM)* - минимальный детерминированный конечный автомат $M = (V, Q_0, F, \Sigma, \delta)$, у которого:
- Множество состояний $V$ соответствует классам эквивалентности подстрок по отношению $\sim_S$.
- Начальное состояние $Q_0 = r$ соответствует пустой строке $\epsilon$.
- Множество терминальных состояний $F$ состоит из классов эквивалентности, содержащих суффиксы всей строки $S$.

> [!INFO] Вложенность правых контекстов
> Для любых двух подстрок $x$ и $y$, если $|x| \le |y|$, то их множества $\text{Endpos}$ либо не пересекаются ($\text{Endpos}(x) \cap \text{Endpos}(y) = \emptyset$), либо $\text{Endpos}(y) \subseteq \text{Endpos}(x)$. Совпадение множеств $\text{Endpos}(x) = \text{Endpos}(y)$ означают принадлежность $x$ и $y$ одному состоянию автомата.

### 2. Устройство класса эквивалентности и понятие Longest

Каждое состояние $v \in V$ автомата агрегирует внутри себя класс эквивалентности подстрок $C(v)$.

**Свойства класса эквивалентности $C(v)$:**
1. Все подстроки из $C(v)$ имеют абсолютно одинаковое множество вхождений $\text{Endpos}$.
2. Каждая строка из $C(v)$ является строгим суффиксом наиболее длинной строки из этого же класса.
3. Длины подстрок, входящих в класс $C(v)$, образуют непрерывный отрезок натуральных чисел $[minlen(v), maxlen(v)]$.

==Опр.== **Longest** *(наидлиннейшая строка класса)* - подстрока $longest(v) \in C(v)$, имеющая максимальную длину среди всех подстрок данного класса эквивалентности:
$$len(v) = maxlen(v) = |longest(v)|$$

#### Критерий Longest

**Утв.** *(Критерий применимости наидлиннейшей строки)*
Подстрока $x$ является $longest$ своего класса эквивалентности $C(v)$ тогда и только тогда, когда выполняется хотя бы одно из условий:
1. $x$ является префиксом всей строки $S$ ($0 \in \text{Endpos}(x) \land |x| = \text{pos} + 1$).
2. В строке $S$ подстрока $x$ имеет хотя бы два различных расширения влево, то есть:
   $$\exists a, b \in \Sigma, a \neq b \ : \ a x \sqsubset S \land b x \sqsubset S$$
   где $a x \sqsubset S$ означает, что $a x$ является подстрокой $S$.

> [!TIP] Интуиция критерия Longest
> Если подстрока $x$ расширяется влево в строке $S$ всегда только одним единственным символом $a$, то множество $\text{Endpos}(a x)$ идентично $\text{Endpos}(x)$, а значит строка $x$ не является длиннейшей в своём классе (строка $a x$ лежит в том же классе и длиннее $x$). Как только появляется расщепление влево (разные символы $a$ и $b$), множества $\text{Endpos}(a x)$ и $\text{Endpos}(b x)$ становятся строго меньше $\text{Endpos}(x)$, фиксируя $x$ как $longest$.

### 3. Атрибуты состояний и суффиксные ссылки

Каждая вершина $v \in V$ суффиксного автомата хранит следующие атрибуты:

1. **$len(v)$** - длина наидлиннейшей строки $longest(v)$ в классе $C(v)$.
2. **$link(v)$** - суффиксная ссылка *(suffix link)*.
3. **$\delta(v, c)$** - переходы по символам $c \in \Sigma$.

==Опр.== **Суффиксная ссылка** *(link)* - указатель из состояния $v$ в состояние $u = link(v)$, соответствующее наибольшему собственному суффиксу строки $longest(v)$, имеющему строго более широкий правый контекст:
$$\text{Endpos}(longest(v)) \subset \text{Endpos}(longest(u))$$

По свойствам классов эквивалентности выполняется соотношение для минимальной длины строки в классе:
$$minlen(v) = len(link(v)) + 1$$

> [!EXAMPLE] Иерархия дерева суффиксных ссылок
> Множество всех состояний $V$ вместе с суффиксными ссылками $link(v)$ образует ориентированное дерево с корнем в $r$ (пустая строка), называемое **деревом суффиксных ссылок** *(Link Tree)*.

### 4. Устройство рёбер в суффиксном автомате

Рёбра автомата задаются функцией переходов $\delta: V \times \Sigma \to V \cup \{\emptyset\}$.

**Свойства переходов:**
1. Переход по символу $c$ из состояния $u$ в состояние $v = \delta(u, c)$ означает, что приписывание символа $c$ справа к любой строке $x \in C(u)$ дает подстроку $x c \in C(v)$.
2. Множество подстрок $C(u) \cdot c = \{ x c \mid x \in C(u) \}$ является подмножеством подстрок класса $C(v)$.
3. Рёбра автомата формируют ориентированный ациклический граф (DAG) с одним истоком в $r$. Любой путь из $r$ по рёбрам автомата однозначно соответствует некоторой подстроке строки $S$.

### 5. Пошаговые алгоритмы построения (Онлайн-алгоритм)

Автомат строится посимвольно слева направо. Пусть построены состояния для префикса $S[:i]$. При добавлении символа $c = s_i$ выполняется обработка новых состояний.

#### Общая схема при дописывании символа $c$

1. Сохранить состояние $last$, соответствующее всей предыдущей строке $S[:i]$.
2. Создать новое состояние $cur$ с $len(cur) = len(last) + 1$.
3. Организовать подъём от $last$ по суффиксным ссылкам $p = last, link(p), \dots$, пока в текущем состоянии $p$ отсутствует переход по символу $c$ ($\delta(p, c) == \emptyset$). На каждом шаге устанавливать $\delta(p, c) = cur$.

---

#### Случай 1 (Новая буква / Отсутствие переходов)

> [!important] Условие Случая 1
> Подъём по суффиксным ссылкам дошёл до фиктивного предка корня ($p = \emptyset$), и ни в одном из состояний пути не было перехода по символу $c$.

**Шаги обработки:**
1) Добавить переходы $\delta(p, c) = cur$ для всех состояний $p$ на пути от $last$ до корня $r$.
2) Установить суффиксную ссылку новой вершины: $link(cur) = r$.
3) Обновить текущий указатель всей строки: $last = cur$.

---

#### Случай 2 (Переход существует, без порождения Clone)

> [!important] Условие Случая 2
> В процессе подъёма по суффиксным ссылкам от $last$ найдено первое состояние $p$, у которого уже есть переход по символу $c$ в некоторое состояние $q = \delta(p, c)$, причём выполняется условие:
> $$len(q) == len(p) + 1$$

**Шаги обработки:**
1) Переходы $\delta(p', c) = cur$ для всех состояний $p'$ ниже $p$ на пути уже установлены.
2) Поскольку $len(q) == len(p) + 1$, строка $longest(q)$ получена простым приписыванием символа $c$ к $longest(p)$, и класс $C(q)$ не содержит более длинных подстрок.
3) Установить суффиксную ссылку: $link(cur) = q$.
4) Обновить текущий указатель всей строки: $last = cur$.

---

#### Случай 3 (Все случаи / С порождением состояния Clone)

> [!important] Условие Случая 3
> Найдено состояние $p$ с переходом $q = \delta(p, c)$, но выполняется условие:
> $$len(q) > len(p) + 1$$

В этом случае класс $C(q)$ содержит строки, которые не получаются приписыванием $c$ к подстрокам из $C(p)$. Требуется расщепить состояние $q$, выделив из него состояние-клон $clone$.

**Пошаговый алгоритм расщепления:**
1) Создать новое состояние $clone$.
2) Скопировать в $clone$ атрибуты и переходы из $q$:
   - $\delta(clone, a) = \delta(q, a) \quad \forall a \in \Sigma$
   - $link(clone) = link(q)$
3) Установить длину клонированного состояния: $len(clone) = len(p) + 1$.
4) Перенаправить суффиксную ссылку состояния $q$: $link(q) = clone$.
5) Установить суффиксную ссылку нового состояния: $link(cur) = clone$.
6) **Перенаправление переходов предков:**
   Продолжить подъём от $p$ по суффиксным ссылкам ($p = link(p)$). Пока $p \neq \emptyset$ и $\delta(p, c) == q$, перенаправлять переход:
   $$\delta(p, c) = clone$$
7) Обновить текущий указатель всей строки: $last = cur$.

### 6. Доказательство асимптотики и сложности

#### Число состояний
Утв. **Верхняя оценка количества состояний**
: Для любой строки $S$ длины $n \ge 2$ количество состояний суффиксного автомата не превосходит:
$$|V| \le 2n - 1$$

*Доказательство:* При добавлении первого символа создаётся 2 состояния ($r$ и $v_1$). Каждый из следующих $n-1$ символов создаёт максимум 2 новых состояния ($cur$ и $clone$). Итого $|V| \le 2 + 2(n-1) - 1 = 2n - 1$.

#### Число переходов
Утв. **Верхняя оценка количества переходов**
: Для любой строки $S$ длины $n \ge 3$ количество переходов в суффиксном автомате не превосходит:
$$|E| \le 3n - 4$$

*Доказательство:* Оценка получается рассмотрением остовного дерева DAG автомата и сопоставлением недревесных рёбер суффиксам строки.

#### Временная сложность построения
Утв. **Линейное время построения**
: Время работы алгоритма построения SAM для строки длины $n$ составляет:
$$T(n) = O(n \cdot |\Sigma|)$$
При хранении переходов в хеш-таблице амортизированное время составляет $O(n)$.

*Доказательство:*
1. Каждый шаг по символу $c$ создаёт не более 2 состояний.
2. Подъём по суффиксным ссылкам при перенаправлении рёбер уменьшает глубину состояний в дереве $Link$. Суммарное количество перенаправлений рёбер за все $n$ шагов ограничено суммарным числом созданных рёбер $O(n)$.
3. Копирование переходов при клонировании требует $O(|\Sigma|)$ действий на одно состояние.

> [!SUCCESS] Достоинства суффиксного автомата
> - Минимально возможное число состояний среди всех автоматов, принимающих подстроки $S$.
> - Онлайн-алгоритм построения (возможность добавлять символы в конец без перестройки всей структуры).
> - Позволяет за $O(1)$ на шаг находить число различных подстрок, позицию первого вхождения и наидлиннейшие общие подстроки.

> - Алфавитная зависимость $O(|\Sigma|)$ при явном копировании таблиц переходов.
