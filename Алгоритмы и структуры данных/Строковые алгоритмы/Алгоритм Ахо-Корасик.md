### Цель и проблематизация

При поиске множества шаблонов $\mathcal{P} = \{P_1, P_2, \dots, P_k\}$ совокупной длины $M = \sum \vert{}P_i\vert{}$ в тексте $T$ длины $n$ последовательное применение алгоритма КМП для каждого шаблона в отдельности требует $O(k \cdot n + M)$ операций.

Алгоритм Ахо-Корасик объёдиняет концепции префиксного дерева (бора) и префикс-функции из КМП, строя детерминированный конечный автомат (ДКА). Введение суффиксных ссылок и явной функции перехода позволяет обрабатывать текст $T$ за однократный проход за время $O(n + M + K_{\text{out}})$, где $K_{\text{out}}$ - суммарное количество найденных вхождений.

---

### Математическая постановка задачи и формальные определения

Пусть $\Sigma$ - алфавит мощности $\vert{}\Sigma\vert{}$. Бор $T = (V, E)$ построен на множестве строк $\mathcal{P}$.
Корень бора обозначается за $r \in V$ и соответствует пустой строке $\epsilon$.
Каждой вершине $v \in V$ сопоставлена строка $w(v)$, получаемая чтением меток рёбер на пути от $r$ к $v$.

==Опр.== **Суффиксная ссылка** *(suffix link)* - отображение $\text{link}: V \to V$, сопоставляющее вершине $v$ вершину $u = \text{link}(v)$, т.ч. строка $w(u)$ является наибольшим собственным суффиксом строки $w(v)$, присутствующим в боре в качестве префикса некоторого ключа из $\mathcal{P}$.

По определению полагается: $\text{link}(r) = r$, а для всех вершин на 1-м уровне от корня: $\forall v \in V : \text{dist}(r, v) = 1 \implies \text{link}(v) = r$.

==Опр.== **Сжатая суффиксная ссылка** *(терминальная ссылка, compressed suffix link / exit link)* - отображение $\text{out\_link}: V \to V \cup \{\emptyset\}$, указвающее на ближайшую вершину $u$, достижимую по цепочке суффиксных ссылок из $v$, т.ч. $u.\text{is\_terminal} == \text{True}$.

==Опр.== **Функция перехода** *(автоматный переход, transition function)* - отображение $\delta: V \times \Sigma \to V$, определяющее шаг ДКА из вершины $v$ по символу $c \in \Sigma$:
$$\delta(v, c) = \begin{cases} u, & \text{если } \exists (v, u) \in E \text{ с меткой } c \\ \delta(\text{link}(v), c), & \text{если } (v, u) \notin E \land v \neq r \\ r, & \text{если } (v, u) \notin E \land v = r \end{cases}$$

> [!INFO] Геометрическая и автоматная интуиция
> Суффиксная ссылка $\text{link}(v)$ представляет собой многомерный аналог значений префикс-функции $\pi[i]$ в алгоритме КМП, перенесённый с одной строки на дерево строк. Функция перехода $\delta(v, c)$ замыкает быстрые откаты, превращая дерево с возвратами в детерминированный автомат, выполняющий каждый шаг за $O(1)$.

### Двухуровневое объяснение

> [!TIP] Интуиция вычисления ссылок через BFS
> Если мы находимся в вершине $v$ и прочитали слово $w(v)$, то длиннейший собственный суффикс этого слова равен $w(\text{link}(v))$. При поступлении нового символа $c$ возможны два случая:
> 1. В боре есть ребро из $v$ по символу $c$ в узел $u$. Тогда суффиксной ссылкой для $u$ будет переход из $\text{link}(v)$ по тому же символу $c$.
> 2. Ребра нет, и нам нужно совершить откат по суффиксной ссылке $\text{link}(v)$.
> Вычисление ссылок в порядке обхода в ширину (BFS) гарантирует, что при обработке вершины на глубине $d$ все суффиксные ссылки для вершин на меньших глубинах $< d$ уже полностью посчитаны.

## Алгоритм Ахо-Корасик построения суффиксных ссылок и функции перехода

> [!important] Цель
> Расчёт суффиксных ссылок $\text{link}(v)$, сжатых суффиксных ссылок $\text{out\_link}(v)$ и построение таблицы автоматных переходов $\delta(v, c)$ для всех вершин $v \in V$ за время $O(\vert{}V\vert{} \cdot \vert{}\Sigma\vert{})$ с помощью обхода в ширину (BFS).

### 1. Алгоритм

1) Создать очередь $Q$.
2) Для корня $r$: положить $\text{link}(r) = r, \text{out\_link}(r) = \emptyset$.
3) Для каждого символа $c \in \Sigma$:
	3.1) Если $\exists (r, u) \in E$ с меткой $c$: положить $\delta(r, c) = u, \text{link}(u) = r, \text{out\_link}(u) = \emptyset$, поместить $u$ в очередь $Q$.
	3.2) Иначе: положить $\delta(r, c) = r$.
4) Пока очередь $Q$ не пуста:
	4.1) Извлечь вершину $v = Q.\text{pop}()$.
	4.2) **Вычисление сжатой суффиксной ссылки:**
	     Если $\text{link}(v).\text{is\_terminal} == \text{True}$, положить $\text{out\_link}(v) = \text{link}(v)$.
	     Иначе положить $\text{out\_link}(v) = \text{out\_link}(\text{link}(v))$.
	4.3) **Вычисление переходов и суффиксных ссылок для сыновей:**
	     Для каждого символа $c \in \Sigma$:
	     - Если $\exists (v, u) \in E$ с меткой $c$:
	       - Положить $\text{link}(u) = \delta(\text{link}(v), c)$.
	       - Положить $\delta(v, c) = u$.
	       - Поместить $u$ в очередь $Q$.
	     - Иначе:
	       - Положить $\delta(v, c) = \delta(\text{link}(v), c)$.
5) Вернуть настроенный автомат.

```python
from collections import deque

class AhoCorasickNode:
    def __init__(self):
        self.children = {}      # Исходные рёбра бора (c -> Node)
        self.go = {}            # Таблица переходов \delta(v, c)
        self.link = None        # Суффиксная ссылка
        self.out_link = None    # Сжатая суффиксная ссылка
        self.is_terminal = False
        self.pattern_id = -1    # Индекс паттерна (если терминальная)

def build_aho_corasick(root: AhoCorasickNode, alphabet: list[str]):
    queue = deque()
    root.link = root
    root.out_link = None
    
    # Обработка корня (глубина 0)
    for c in alphabet:
        if c in root.children:
            u = root.children[c]
            root.go[c] = u
            u.link = root
            u.out_link = None
            queue.append(u)
        else:
            root.go[c] = root

    # Обход в ширину (BFS)
    while queue:
        v = queue.popleft()
        
        # Расчёт сжатой суффиксной ссылки
        if v.link.is_terminal:
            v.out_link = v.link
        else:
            v.out_link = v.link.out_link

        # Расчёт переходов и ссылок для сыновей
        for c in alphabet:
            if c in v.children:
                u = v.children[c]
                u.link = v.link.go[c]
                v.go[c] = u
                queue.append(u)
            else:
                v.go[c] = v.link.go[c]

```

#### Асимптотика

* **Временная сложность:** Обход BFS посещает каждую вершину $v \in V$ ровно один раз. Для каждой вершины происходит перебор символов алфавита $\Sigma$ за $O(|\Sigma|)$ при использовании явных массивов или хеш-таблиц. Итоговая временная сложность построения :

$$T_{\text{build}} = O(|V| \cdot |\Sigma|)$$


* **Пространственная сложность:** Для хранения таблицы переходов $\delta(v, c)$, а также ссылок $\text{link}$ и $\text{out\_link}$ требуется $O(|V| \cdot |\Sigma|)$ памяти.

#### Корректность

Доказательство проводится индукцией по глубине вершин $d = \text{depth}(v)$ в боре.

* **База индукции ($d = 0, d = 1$):**
* Для корня $r$ ($d=0$) по определению $\text{link}(r) = r$.
* Для сыновей корня $u$ ($d=1$) длина $w(u)$ равна 1. Единственный собственный суффикс длины 0 есть пустая строка $\epsilon = w(r)$. Следовательно, $\text{link}(u) = r$, что алгоритм прямо заносит на шаге 3.1.


* **Индукционное предположение:** Пусть для всех вершин на глубине $< d$ ссылки $\text{link}$ и переходы $\delta$ вычислены верно.
* **Шаг индукции:** Рассмотрим вершину $u$ на глубине $d$, являющуюся сыном $v$ по символу $c$ ($\text{depth}(v) = d-1$).
1. Строка $w(u) = w(v) + c$. Любой собственный суффикс строки $w(u)$ имеет вид $S' + c$, где $S'$ - собственный суффикс строки $w(v)$.
2. Чтобы суффикс $S' + c$ был максимальной длины и присутствовал в боре, подстрока $S'$ должна быть длиннейшим собственным суффиксом $w(v)$, имеющим переход по символу $c$.
3. По предположению индукции, результат такого перехода из $\text{link}(v)$ по символу $c$ уже верно вычислен в таблице $\delta(\text{link}(v), c)$.
4. Следовательно, $\text{link}(u) = \delta(\text{link}(v), c)$, что алгоритм и присваивает на шаге 4.3.
5. Корректность вычисления $\text{out\_link}(v)$ следует из того, что ближайшая терминальная вершина на пути по суффиксным ссылкам из $v$ либо совпадает с $\text{link}(v)$, либо совпадает с $\text{out\_link}(\text{link}(v))$. Корректность доказана.



#### Пример применения

Пусть $\mathcal{P} = \{\text{"a"}, \text{"ab"}, \text{"bc"}\}$, алфавит $\Sigma = \{\text{'a'}, \text{'b'}, \text{'c'}\}$.
Вершины бора:

* $r = \epsilon$ (корень)
* $v_a = \text{"a"}$ (терминальная, id=0)
* $v_{ab} = \text{"ab"}$ (терминальная, id=1)
* $v_b = \text{"b"}$
* $v_{bc} = \text{"bc"}$ (терминальная, id=2)

Исполнение BFS:

1. **Инициализация корня ($r$):**
* $\delta(r, \text{'a'}) = v_a$, $\text{link}(v_a) = r$.
* $\delta(r, \text{'b'}) = v_b$, $\text{link}(v_b) = r$.
* $\delta(r, \text{'c'}) = r$.
* Очередь $Q = [v_a, v_b]$.


2. **Извлечение $v_a$ ($\text{"a"}$):**
* $\text{out\_link}(v_a) = \emptyset$ (т.к. $\text{link}(v_a) = r$ не терминальная).
* Символ $\text{'b'}$: есть ребро в $v_{ab} \implies \text{link}(v_{ab}) = \delta(\text{link}(v_a), \text{'b'}) = \delta(r, \text{'b'}) = v_b$.
* Символ $\text{'c'}$: нет ребра $\implies \delta(v_a, \text{'c'}) = \delta(r, \text{'c'}) = r$.


3. **Извлечение $v_b$ ($\text{"b"}$):**
* Символ $\text{'c'}$: есть ребро в $v_{bc} \implies \text{link}(v_{bc}) = \delta(\text{link}(v_b), \text{'c'}) = \delta(r, \text{'c'}) = r$.


4. **Извлечение $v_{ab}$ ($\text{"ab"}$):**
* $\text{link}(v_{ab}) = v_b$. Так как $v_b$ не терминальная, $\text{out\_link}(v_{ab}) = \text{out\_link}(v_b) = \emptyset$.


5. **Итог:** Для узла $v_{ab}$ ($\text{"ab"}$) суффиксная ссылка указвает на $v_b$ ($\text{"b"}$), т.к. $\text{"b"}$ - максимальный собственный суффикс строки $\text{"ab"}$.
