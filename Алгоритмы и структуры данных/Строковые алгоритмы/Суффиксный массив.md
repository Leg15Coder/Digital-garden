### Цель и проблематизация

При анализе подстрок и поиске шаблонов в строке $S$ длины $n$ наивные алгоритмы требуют $O(n^2)$ или $O(n \cdot m)$ операций. Использование суффиксного дерева позволяет решать эти задачи за $O(n)$, однако оно обладает высокими накладными расходами памяти $O(n \cdot \vert{}\Sigma\vert{})$ из-за хранения структуры указателей и узлов.

**Суффиксный массив** *(Suffix Array, SA)* представляет собой эффективную и компактную альтернативу суффиксному дереву. Он хранит отсортированный лексикографический порядок всех суффиксов строки в виде чистого массива целых чисел. Это позволяет сократить потребление памяти до строгого $O(n)$ с минимальной константой, сохраняя возможность быстрого поиска подстрок за $O(m \log n)$ (или $O(m + \log n)$ с использованием LCP).

### Математическая постановка задачи и формальные определения

Пусть $S = s_0 s_1 \dots s_{n-1}$ - строка длины $n$ над алфавитом $\Sigma$. К строке в конец приписывается специальный терминальный символ $\$ \notin \Sigma$, наименьший по лексикографическому порядку: $\forall c \in \Sigma : \$ < c$.

Обозначим $S[i:] = s_i s_{i+1} \dots s_{n-1}\$$ суффикс строки $S$, начинающийся с индекса $i$.

==Опр.== **Суффиксный массив** *(SA)* - перестановочный массив $P = (p_0, p_1, \dots, p_{n-1})$ индексов $0, \dots, n-1$, задающий лексикографический порядок всех суффиксов строки $S$:
$$S[p_0:] < S[p_1:] < \dots < S[p_{n-1}:]$$

==Опр.== **Класс эквивалентности циклического сдвига** *(массив $C$)* - массив $C$ длины $n$, где $C[i]$ определяет ранг эквивалентности циклического сдвига длины $2^k$, начинающегося в позиции $i$, среди всех отсортированных циклических сдвигов этой длины.

> [!INFO] Замена суффиксов циклическими сдвигами
> Приписывание уникального терминального символа $\$$ на последнюю позицию делает сравнение суффиксов строго эквивалентным сравнению циклических сдвигов строки $S\$$. Символ $\$$ завершает любой суффикс раньше, чем начнутся повторяющиеся символы при циклических переходах.

### Двухуровневое объяснение

> [!TIP] Интуиция удвоения длины $2^k \to 2^{k+1}$
> Идея алгоритма за $O(n \log n)$ заключается в последовательном увеличении длин сравниваемых подстрок по степеням двойки $2^k$. Чтобы сравнить два блока длины $2^{k+1}$, начинающиеся в позициях $i$ и $j$, мы разбиваем каждый из них на две половинки длины $2^k$: левую $[i \dots i + 2^k - 1]$ и правую $[i + 2^k \dots i + 2^{k+1} - 1]$. Поскольку лексикографический порядок всех блоков длины $2^k$ уже известен и закодирован в классах эквивалентности $C$, сравнение двух блоков длины $2^{k+1}$ сводится к сравнению пар рангов $(C[i], C[(i + 2^k) \bmod n])$ и $(C[j], C[(j + 2^k) \bmod n])$ за $O(1)$!

> [!EXAMPLE] Бытовая аналогия с двоичной сортировкой
> Представьте сортировку длинных ведомостей. Вместо того чтобы сравнивать буквы поодиночке, вы сначала сортируете отдельные символы ($2^0=1$), затем блоки по 2 символа ($2^1=2$), затем по 4 символа ($2^2=4$) и т.д. На каждом шаге порядок блоков длины $2^{k+1}$ получается мгновенно путем устойчивой сортировки пар, состоящих из рангов первой и второй половинок блока.

### Алгоритм построения суффиксного массива

> [!important] Цель
> Построение суффиксного массива $P$ и классов эквивалентности $C$ за время $O(n \log n)$ с помощью удвоения длин и поразрядной сортировки подсчётом (Radix Sort).

#### 1. Алгоритм

1) **Базовый шаг ($k = 0$, длина $2^0 = 1$):**
   1.1) Отсортировать символы строки $S\$$ длины $n$ за $O(n + \vert{}\Sigma\vert{})$ с помощью сортировки подсчётом. Сформировать начальный массив перестановок $P$.
   1.2) Вычислить начальные классы эквивалентности $C[p_0] = 0$. Пройти по $P$: если $S[p_i] \neq S[p_{i-1}]$, то $C[p_i] = C[p_{i-1}] + 1$, иначе $C[p_i] = C[p_{i-1}]$.
2) **Итеративный шаг удвоения ($k \to k + 1$, длина $2^{k+1} \le 2n$):**
   2.1) Каждой позиции $i$ соответствует пара рангов половин длины $2^k$: $(C[i], C[(i + 2^k) \bmod n])$.
   2.2) Сдвинуть элементы массива $P$ влево на $2^k$: $P'_{i} = (P_i - 2^k + n) \bmod n$. Этим достигается отсортированность элементов $P'$ по второй компоненте пары!
   2.3) Применить устойчивую сортировку подсчётом к массиву $P'$ по первой компоненте пары (по массиву классов $C$). Получить новый массив $P$.
   2.4) Пересчитать новые классы эквивалентности $C_{\text{new}}$ за $O(n)$: пара $(C[p_i], C[(p_i + 2^k) \bmod n])$ сравнивается с парой $(C[p_{i-1}], C[(p_{i-1} + 2^k) \bmod n])$.
   2.5) Присвоить $C = C_{\text{new}}$. Если число классов $C[p_{n-1}] + 1 == n$, завершить алгоритм досрочно.
3) Вернуть массив $P$.

```python
def build_suffix_array(s: str) -> list[int]:
    s += "$"
    n = len(s)
    alphabet = 256

    # Шаг 0: k = 0, длина 2^0 = 1
    cnt = [0] * max(alphabet, n)
    p = [0] * n
    c = [0] * n

    for char in s:
        cnt[ord(char)] += 1
    for i in range(1, alphabet):
        cnt[i] += cnt[i - 1]
    for i in range(n - 1, -1, -1):
        cnt[ord(s[i])] -= 1
        p[cnt[ord(s[i])]] = i

    c[p[0]] = 0
    classes = 1
    for i in range(1, n):
        if s[p[i]] != s[p[i - 1]]:
            classes += 1
        c[p[i]] = classes - 1

    # Шаги удвоения k -> k + 1
    pn = [0] * n
    cn = [0] * n
    k = 0
    while (1 << k) < n:
        shift = 1 << k
        # Сдвиг влево на 2^k (упорядочивание по 2-й компоненте)
        for i in range(n):
            pn[i] = (p[i] - shift + n) % n

        # Устойчивая сортировка подсчётом по 1-й компоненте
        cnt = [0] * classes
        for i in range(n):
            cnt[c[pn[i]]] += 1
        for i in range(1, classes):
            cnt[i] += cnt[i - 1]
        for i in range(n - 1, -1, -1):
            cnt[c[pn[i]]] -= 1
            p[cnt[c[pn[i]]]] = pn[i]

        cn[p[0]] = 0
        classes = 1
        for i in range(1, n):
            mid1 = (p[i] + shift) % n
            mid2 = (p[i - 1] + shift) % n
            if c[p[i]] != c[p[i - 1]] or c[mid1] != c[mid2]:
                classes += 1
            cn[p[i]] = classes - 1
        c = cn[:]
        if classes == n:
            break
        k += 1

    return p

```

#### 2. Асимптотика

* **Временная сложность:**
* Базовый шаг ($k=0$): сортировка подсчётом символов за $O(n + |\Sigma|)$.


* Итеративный процесс: цикл по степеням двойки выполняется $\lceil \log_2 n \rceil$ раз. На каждой итерации формирование $P'$, сортировка подсчётом и обновление $C$ забирают $O(n)$ действий.


* Итоговая сложность:

$$T(n) = O(n + |\Sigma|) + \sum\limits_{k=0}^{\lceil \log_2 n \rceil - 1} O(n) = O(n \log n)$$




* **Пространственная сложность:**
* Массивы $P, C, P_{\text{new}}, C_{\text{new}}$ и массив частот $cnt$ имеют размер $O(n + |\Sigma|)$.
* Итоговая память: $O(n + |\Sigma|)$ (или $O(n)$ при $|\Sigma| \le n$).



#### 3. Математическое доказательство

Утв. **Корректность устойчивой сортировки пар и сохранения порядка**
: Если элементы массива $P'$ предварительно упорядочены по второй компоненте пары $C[(i + 2^k) \bmod n]$, то последующая устойчивая сортировка подсчётом по первой компоненте $C[i]$ даёт корректный лексикографический порядок пар длины $2^{k+1}$.

##### Доказательство

1. Для любых двух позиций $i$ и $j$ подстрока длины $2^{k+1}$ представима в виде пары подстрок длины $2^k$:

$$A_i = (S[i \dots i + 2^k - 1], S[i + 2^k \dots i + 2^{k+1} - 1])$$


$$A_j = (S[j \dots j + 2^k - 1], S[j + 2^k \dots j + 2^{k+1} - 1])$$


2. По индукционному предположению классы эквивалентности $C$ на этапе $k$ монотонно отражают порядок блоков длины $2^k$:

$$S[i \dots i + 2^k - 1] < S[j \dots j + 2^k - 1] \iff C[i] < C[j]$$


$$S[i \dots i + 2^k - 1] = S[j \dots j + 2^k - 1] \iff C[i] = C[j]$$


3. Каждой позиции $i$ сопоставим пару рангов $(C[i], C[(i + 2^k) \bmod n])$.
4. По определению лексикографического порядка на парах:

$$(C[i], C[(i + 2^k) \bmod n]) < (C[j], C[(j + 2^k) \bmod n])$$


$$\iff C[i] < C[j] \lor (C[i] == C[j] \land C[(i + 2^k) \bmod n] < C[(j + 2^k) \bmod n])$$


5. Элементы $P'$ получены сдвигом $P_i - 2^k$, поэтому они уже упорядочены по второй компоненте $C[(i + 2^k) \bmod n]$. Устойчивая сортировка подсчётом по первой компоненте $C[i]$ сохраняет порядок элементов с равными $C[i]$, что строго соответствует определению порядка пар.


6. При достижении длины $2^k \ge n$ порядок циклических сдвигов длины $2^k$ полностью совпадает с лексикографическим порядком всех суффиксов строки $S$. Корректность доказана.

#### 4. Пример применения

Пусть $S = \text{"ab"}$, $n = 3$ (с учётом $\$$: $S = \text{"ab\$"}$).

* $k = 0$ (длина 1):
* Символы: $S[0]=\text{'a'}, S[1]=\text{'b'}, S[2]=\text{'\$'}$.
* Сортировка символов: $P = [2, 0, 1]$ (соответствуют $\$, \text{'a'}, \text{'b'}$).
* Классы: $C[2] = 0, C[0] = 1, C[1] = 2$.


* $k = 1$ (длина $2^1 = 2 \ge 3$):
* Сдвиг $P'$ на 1 влево: $P' = [1, 2, 0]$.
* Сортировка по первой компоненте $C$: $P = [2, 0, 1]$.
* Новые классы уникальны: $C = [1, 2, 0]$.


* Итог: $P = [2, 0, 1]$, что соответствует суффиксам $\$, \text{"ab\$"}, \text{"b\$"}$.
