В табличном [[Введение в обучение с подкреплением|MDP]] с конечными множествами состояний $|\mathcal{S}| < \infty$ и действий $|\mathcal{A}| < \infty$ общее число детерминированных [[Введение в обучение с подкреплением|стратегий]] равно $|\mathcal{A}|^{|\mathcal{S}|}$, т.ч. прямой перебор всех стратегий для поиска оптимальной вычислительно невозможен. Методы динамического программирования решают эту задачу за счёт итеративного применения [[Уравнение Беллмана|уравнений Беллмана]].

==Опр.== **Оптимальная функция ценности** *(Optimal Value Function, $V^*(s)$)* - поточечный максимум [[Введение в обучение с подкреплением|функции ценности состояния]] по всем допустимым стратегиям, удовлетворяющий нелинейному **уравнению оптимальности Беллмана**:$$V^*(s) = \max\limits_\pi V^\pi(s) = R(s) + \max\limits_{a \in \mathcal{A}} \gamma \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') V^*(s')$$
==Опр.== **Оптимальная стратегия** *(Optimal Policy, $\pi^*(s)$)* - детерминированная стратегия, выбирающая в каждом состоянии $s \in \mathcal{S}$ действие, максимизирующее ожидаемую ценность следующего состояния по $V^*$:$$\pi^*(s) = \arg\max\limits_{a \in \mathcal{A}} \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') V^*(s')$$
*(При функции награды вида $R(s, a)$ под знаком $\arg\max\limits_{a \in \mathcal{A}}$ сохраняется выражение $R(s, a) + \gamma \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') V^*(s')$, тогда как для $R(s)$ величины $R(s)$ и $\gamma > 0$ не влияют на точку максимума по $a$)*.

==Опр.== **Оператор Беллмана** *(Bellman Operator, $B^\pi$ и $B$)* - отображение $\mathbb{R}^{|\mathcal{S}|} \to \mathbb{R}^{|\mathcal{S}|}$, задающее правую часть соответствующего уравнения Беллмана $\forall s \in \mathcal{S}$:$$[B^\pi V](s) = R(s) + \gamma \sum\limits_{s' \in \mathcal{S}} P_{s\pi(s)}(s') V(s'), \quad [B V](s) = R(s) + \max\limits_{a \in \mathcal{A}} \gamma \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') V(s')$$

### Сжимающее свойство оператора Беллмана

==Утв.== Оператор оптимальности Беллмана $B$ является [[Метрическое пространство#Сжимающий оператор|сжимающим оператором]] в [[Метрическое пространство#^030edd|полном метрическом пространстве]] $(\mathbb{R}^{|\mathcal{S}|}, d_\infty)$ с коэффициентом сжатия $\gamma \in [0; 1)$, т.ч. последовательность $V_{k+1} = B V_k$ сходится к единственной [[Метрическое пространство#Сжимающий оператор|неподвижной точке]] $V^*$ из любого начального приближения $V_0$.

#### Доказательство

1. Введём равномерную норму $\|U\|_\infty = \max\limits_{s \in \mathcal{S}} |U(s)|$ и метрику $d_\infty(U, W) = \|U - W\|_\infty$. Зафиксируем произвольные $U, W \in \mathbb{R}^{|\mathcal{S}|}$ и состояние $s \in \mathcal{S}$.
2. Оценим модуль разности $[BU](s) - [BW](s)$, используя свойство $|\max\limits_{a \in \mathcal{A}} f(a) - \max\limits_{a \in \mathcal{A}} g(a)| \le \max\limits_{a \in \mathcal{A}} |f(a) - g(a)|$:$$|[BU](s) - [BW](s)| = \left| \max\limits_{a \in \mathcal{A}} \gamma \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') U(s') - \max\limits_{a \in \mathcal{A}} \gamma \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') W(s') \right| \le \gamma \max\limits_{a \in \mathcal{A}} \left| \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') \left( U(s') - W(s') \right) \right|$$
3. Применим неравенство $\triangle$-ка и учтём, что $P_{sa}(s') \ge 0$ и $\sum\limits_{s' \in \mathcal{S}} P_{sa}(s') = 1$:$$\gamma \max\limits_{a \in \mathcal{A}} \left| \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') \left( U(s') - W(s') \right) \right| \le \gamma \max\limits_{a \in \mathcal{A}} \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') |U(s') - W(s')| \le \gamma \max\limits_{a \in \mathcal{A}} \left( \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') \right) \|U - W\|_\infty = \gamma \|U - W\|_\infty$$
4. Переходя к максимуму по $s \in \mathcal{S}$ в левой части, получаем условие сжатия:$$\|BU - BW\|_\infty \le \gamma \|U - W\|_\infty$$
5. По [[Теорема Банаха|Т. Банаха]] $\exists ! \tilde{V} \in \mathbb{R}^{|\mathcal{S}|}\ :\ \tilde{V} = B\tilde{V}$, причём $\|V_k - \tilde{V}\|_\infty \le \gamma^k \|V_0 - \tilde{V}\|_\infty \xrightarrow[k \to \infty]{} 0$. Т.к. $\forall \pi\ :\ V^\pi \le B V^\pi$ и оператор $B$ монотонен ($U \le W \implies BU \le BW$), то $V^\pi \le B^k V^\pi \xrightarrow[k \to \infty]{} \tilde{V}$, а жадная по $\tilde{V}$ стратегия достигает $\tilde{V} \implies \tilde{V} \equiv V^*$.

### Алгоритм Value Iteration

Алгоритм работает в пространстве оценочных функций $\mathbb{R}^{|\mathcal{S}|}$, строя последовательность приближений $V_{k+1} = B V_k$ без явного хранения стратегии. Оптимальная стратегия $\pi^*$ восстанавливается однократным жадным проходом после сходимости.

Вход: MDP $(\mathcal{S}, \mathcal{A}, P_{sa}, \gamma, R)$, порог точности $\varepsilon > 0$.
1. Инициализировать $V_0(s) = 0\ \forall s \in \mathcal{S}$, положить $k = 0$.
2. Повторять до выполнения критерия $\max\limits_{s \in \mathcal{S}} |V_k(s) - V_{k-1}(s)| < \varepsilon$:
	1. Для каждого состояния $s \in \mathcal{S}$ вычислить синхронное обновление:$$V_{k+1}(s) = R(s) + \max\limits_{a \in \mathcal{A}} \gamma \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') V_k(s')$$
	2. Увеличить счётчик итераций: $k \leftarrow k + 1$.
3. Восстановить оптимальную стратегию $\forall s \in \mathcal{S}$:$$\pi^*(s) = \arg\max\limits_{a \in \mathcal{A}} \sum\limits_{s' \in \mathcal{S}} P_{sa}(s') V_k(s')$$

> [!TIP] Интерпретация через конечный горизонт планирования
> При нулевой инициализации $V_0(s) = 0\ \forall s \in \mathcal{S}$ значение $V_k(s)$ на $k$-й итерации равно точной максимальной награде, которую агент может собрать за горизонт планирования в $k$ шагов. С каждой итерацией сигнал награды распространяется по графу переходов на один шаг назад от терминальных состояний к начальным.

> [!EXAMPLE] Пример: **Линейный лабиринт**
> Рассмотрим мир из четырёх состояний $s_1, s_2, s_3, s_4$ при $\gamma = 0.9$, где $s_1$ - терминальная пропасть, $s_4$ - терминальное сокровище, а награда начисляется за переход:
> * Из $s_2$: шаг влево (в $s_1$) даёт $-10$, шаг вправо (в $s_3$) даёт $-1$.
> * Из $s_3$: шаг влево (в $s_2$) даёт $-1$, шаг вправо (в $s_4$) даёт $+10$.
>
> Динамика обновлений Value Iteration:
> * $V_0 = (0, 0, 0, 0)$ - начальная инициализация.
> * $V_1 = (0, -1, 10, 0)$ - учёт мгновенных наград: из $s_2$ выгоднее шаг вправо ($-1 > -10$), из $s_3$ - шаг в $s_4$ ($+10$).
> * $V_2 = (0, 8, 10, 0)$ - в $s_2$ учитывается ценность соседнего $s_3\ :\ \max(-10 + 0.9 \cdot 0, -1 + 0.9 \cdot 10) = 8$.
> * $V_3 = (0, 8, 10, 0)$ - алгоритм сошёлся за 2 шага, т.к. длина оптимальной траектории до терминального состояния не превосходит $2$.

#### Асимптотика

1. Сложность одной итерации по времени: $O(|\mathcal{S}|^2 |\mathcal{A}|)$, т.к. $\forall s \in \mathcal{S}$ и $\forall a \in \mathcal{A}$ вычисляется сумма по $|\mathcal{S}|$ следующим состояниям.
2. Число итераций до точности $\varepsilon$: $O\left(\frac{\log(1/\varepsilon)}{1 - \gamma}\right)$ в силу геометрической скорости сходимости со знаменателем $\gamma$.
3. Сложность по памяти: $O(|\mathcal{S}|^2 |\mathcal{A}|)$ - хранение тензора переходных вероятностей $P_{sa}(s')$ и $O(|\mathcal{S}|)$ для вектора $V \in \mathbb{R}^{|\mathcal{S}|}$.
